# Аудит доступности клиента, 2026-11-17

История: [S11.11](../backlog/E11-dx-docs/S11.11.md). Аудит только читает: исходники не менялись. Браузера и программы чтения с экрана в контейнере нет, поэтому проверка идёт по разметке и стилям, контраст — расчётом.

## 1. Резюме

- **Проверено:** все шаблоны клиента (`.html` и встроенные в `.ts`) скриптом по правилам: изображения без `alt`, кнопки без доступного имени, таблицы без подписи, поля без метки; затем вручную чтением страницы входа, каркас приложения (`app.component.html`), общий набор стилей (`kit.scss`), токены темы.
- **Условия:** `pnpm check` до аудита проходит (18 шагов), тема «Табло» собрана ([S10.12](../backlog/E10-product-features/S10.12.md)).
- **Итого:** 4 группы находок: 0 высоких, 2 средних, 2 низких. Основа хорошая: есть ссылка «к содержимому», ориентиры `header`/`nav`/`main`/`footer`, видимый фокус для всех элементов, подписи полей входа с `aria-invalid` и `role="alert"` для ошибки, отключение движения при `prefers-reduced-motion`, 18 пар цвета темы не ниже 4,5:1 (проверяет `client/scripts/contrast.test.mjs`).
- **Главный вывод:** слабое место — старые страницы на Angular Material (список и карточки матчей, таблица игроков, форма матча): иконки-кнопки без текстового имени и таблицы без подписи. Новые страницы «Табло» устроены правильно.

## 3. Находки

### А. Иконки-кнопки без доступного имени. Средняя. Проверено чтением.

Критерий 4.1.2. Кнопка `mat-icon-button` содержит только `mat-icon` (Material помечает иконку `aria-hidden`), текста и `aria-label` нет: программа чтения с экрана произнесёт «кнопка».

| Файл                                                                                    | Кнопка                                         |
| --------------------------------------------------------------------------------------- | ---------------------------------------------- |
| `pages/game-details/ui/game-details/game-details.component.html:18`                     | скопировать id матча                           |
| `pages/player-details/ui/player-details/player-details.component.html:26`               | скопировать id игрока                          |
| `pages/game-edit/ui/game-form-page/game-form-page.component.html:146,154`               | поменять составы местами, ручка перетаскивания |
| `pages/player-list/ui/players-table/players-table.component.html:239,249,258`           | открыть игрока, править, удалить               |
| `features/player-select/ui/players-autocomplete/players-autocomplete.component.html:11` | убрать фишку игрока (`matChipRemove`)          |

Исправление: `aria-label` с действием и объектом («Copy game id», «Delete player Falcon»).
Воспроизведение: открыть страницу с программой чтения (или панель доступности браузера) и перейти Tab на кнопку.

### Б. Таблицы без подписи. Средняя. Проверено скриптом по разметке.

Критерий 1.3.1. 12 из 21 таблицы без `<caption>`: старые на Material (`captains-table`, `captains-toggle`, `games-table`, `players-toggle`, `players-table`, `game-details`) и пять на новых страницах (`admin-players` ×2, `admin-wizard`, `captains-board`, `compare-systems`, `seasons`). Остальные 9 с подписью, в том числе таблицы игроков и матчей новых досок.
Исправление: `<caption class="k-visually-hidden">` по образцу доски игроков; в `mat-table` подпись добавляется так же внутри `<table>`.

### В. Размер цели 40 px при желательных 44. Низкая. Проверено по токенам.

Критерий 2.5.8 (минимум 24 px) выполнен: `--sfl-target: 40px`. Для основных действий на телефоне в истории [S10.55](../backlog/E10-product-features/S10.55.md) задано 44 px.
→ S10.55, отдельной истории нет.

### Г. Цвета Material в старых страницах не проверены. Низкая. Гипотеза.

Иконки `color="warn"` и `color="primary"` берут цвет темы Material, а не токены `--sfl-*`; контраст этих пар расчётом не проверялся (тест покрывает только токены). Старые страницы заменяются новыми ([S10.72](../backlog/E10-product-features/S10.72.md)).
→ S10.72, отдельной истории нет.

## 4. Что в порядке (проверено)

- Поля входа: `<label for>`, `autocomplete`, `aria-invalid` после касания, сообщение под полем, ошибка входа в `role="alert"`.
- Каркас: ссылка «к содержимому» (`.skip`), `header`, `nav`, `main#main`, `footer`; `lang="en"` на `html`.
- Фокус: общий `:focus-visible` в `kit.scss`; движение выключается при `prefers-reduced-motion: reduce`.
- Изображения: у всех `img` в шаблонах есть `alt` (проверено скриптом); у декоративных стрелок сортировки `aria-hidden`.
- Поля с флажком внутри `<label>`; чекбоксы без отдельной метки не найдены.
- Контраст 18 пар токенов тёмной темы (текст на фоне, акцент, ошибка, цвета команд): не ниже 4,5:1.

## 6. Что не проверено

- Обход с клавиатуры и порядок фокуса на живых страницах, чтение программой экрана, масштаб 200 % и ширина 360 px (reflow): нужен браузер.

- Роли и `aria` внутри компонентов Material (диалоги, автодополнение, chips): чтением кода шаблонов, поведение в браузере не проверялось.
