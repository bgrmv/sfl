# Аудит клиента по практикам Angular (skill `angular-developer`)

Дата: 2026-11-13. Формат — skill `audit-report`, практики — skill `angular-developer` (Angular 22.2, справочники `components`, `signals`, `forms`, `http-client`, `route-guards`, `angular-animations`, `error-boundary`, `testing`). Исходники не менялись. Структура слоёв (FSD) разобрана отдельно: [fsd-client-2026-11-13.md](fsd-client-2026-11-13.md). Состояние интерфейса (обратная связь, загрузка, пустые состояния) — отдельный аудит дизайна.

Базовая проверка: `pnpm check --all` проходит (15 шагов, Node 22.23; в контейнере пока 22.16, нужна пересборка). Данные — подсчёты по `client/src` без `*.spec.ts` (41 компонент, 10 спеков).

## 1. Резюме

- Клиент уже на Angular 22.2: standalone, `inject()` (98 использований против 5 конструкторов), новый control flow (47 `@if`, 17 `@for`, ни одного `NgModule`), lazy-маршруты, `OnPush` у 31 компонента. Это сильная сторона.
- Находок: **9** (подтверждено подсчётом или чтением кода: 8, гипотеза: 1). Высокая: 0, средняя: 5, низкая: 4.
- Главные выводы:
  1. **Не защищены клиентские маршруты:** `games/create`, `/players` и детали игрока открыты без `authGuard`, guard стоит только на `edit` ([S3.10](../backlog/E03-architecture/S3.10.md)). Сервер права проверяет, поэтому это UX и утечка интерфейса, а не обход авторизации.
  2. **Нет ни глобального `ErrorHandler`, ни `@boundary`, ни интерцептора ошибок**, при этом `@angular/animations` и пустой `provideStore()` (NgRx classic) подключены, но не используются.
  3. **Реактивность на RxJS вручную:** 33 `.subscribe()`, 34 `takeUntil`, базовый класс `BaseUnsubscribeComponent` вместо `async`/`toSignal`/`httpResource`; 51 использование реактивных форм, Signal Forms нет (решение владельца: пилот в [S3.16](../backlog/E03-architecture/S3.16.md)).
  4. **Следы миграции:** `ChangeDetectionStrategy.Eager` у 10 компонентов, 4 `@Input()`, `zone.js` остаётся ([S3.15](../backlog/E03-architecture/S3.15.md)).
