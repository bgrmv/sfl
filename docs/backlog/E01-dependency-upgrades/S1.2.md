## Заметки

- Версия Node — 22 (в `.nvmrc` и `engines.node: >=22.0.0 <23`): это версия dev-контейнера (`javascript-node:1-22`), её поддерживают и текущий Angular 18, и целевые Angular/Nest. Node 24 пока нельзя: Angular 18/19 его не поддерживает (CLI 18 откажется работать). Переход на 24 — после Angular 20 вместе с обновлением контейнера; для Angular 22 нужен Node ≥ 22.22.3. Матрица совместимости — в [upgrades.md](../../upgrades.md). pnpm — 9.12.3 (`packageManager`), `.devcontainer/post-create.sh` читает версию оттуда.
- Корневой `staticwebapp.config.json` удалён: Azure берёт конфиг из `client/staticwebapp.config.json`, а проект заморожен ([решение 8](../README.md)).
- **AC про CI снят (решение 2026-11-13):** в репозитории нет workflow ([решение 8](../README.md)), ставить Node в CI нечему. Пункт перенесён в [S2.1](../E02-tests-ci/S2.1.md) (P4): там при создании CI брать версии из `.nvmrc` и `packageManager`.
