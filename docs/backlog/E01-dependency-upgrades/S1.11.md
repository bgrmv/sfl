# S1.11 — Автоматические обновления зависимостей

**Эпик:** 1 — Обновление зависимостей и инструментов · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S2.1](../E02-tests-ci/S2.1.md)

**DESC:** Как разработчик, я хочу, чтобы обновления зависимостей приходили автоматическими PR, чтобы проект больше не отставал на несколько мажоров.

**ACs:**
- [ ] Настроен Renovate или Dependabot для `client/`, `server-nest/` (пока он есть) и GitHub Actions.
- [ ] Минорные и патч-обновления группируются в один PR в неделю.
- [ ] PR от бота проходят обязательный CI ([S2.1](../E02-tests-ci/S2.1.md)).
