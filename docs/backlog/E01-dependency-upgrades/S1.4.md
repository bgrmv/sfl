# S1.4 — Обновить Angular до актуального мажора

**Эпик:** 1 — Обновление зависимостей и инструментов · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** L · **Зависит от:** [S1.1](../E01-dependency-upgrades/S1.1.md), [S2.1](../E02-tests-ci/S2.1.md)

**DESC:** Как разработчик, я хочу клиент на актуальной версии Angular, чтобы получать исправления безопасности и не копить отставание.

**ACs:**
- [ ] Обновление выполнено через `ng update` по одному мажору за раз. Каждый шаг — отдельный коммит, сборка и тесты проходят.
- [ ] Вместе с Angular обновлены `@angular/material`, `@angular/cdk`, `@ngrx/*`, `@angular-eslint/*`.
- [ ] Сборщик переведён с `@angular-devkit/build-angular:browser` на `application` (esbuild). Путь к результату сборки учтён в CI.
- [ ] Приложение вручную проверено на ключевых страницах: главная, вход, список матчей, матч, игроки, игрок.
- [ ] Решение по zoneless-режиму записано в ADR ([S3.9](../E03-architecture/S3.9.md)): переходим или нет.
