# S11.11 — Аудит доступности и UI на Angular Material

**Эпик:** 11 — DX, документация, чистота репозитория · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S11.8](S11.8.md), [S10.12](../E10-product-features/S10.12.md)

**DESC:** Как пользователь, я хочу, чтобы сайт был удобен с клавиатуры, читаем на телефоне и контрастен, чтобы им могли пользоваться все игроки и болельщики.

**ACs:**

- [x] Аудит выполнен после появления темы ([S10.12](../E10-product-features/S10.12.md)), чтобы проверять уже новые цвета.
- [x] Проверены страницы входа, списка матчей, матча, списка игроков и игрока. Критерии: контраст текста и элементов по WCAG AA, фокус и порядок обхода с клавиатуры, подписи у полей и иконок-кнопок, роли и `aria`-атрибуты компонентов Material, читаемость на ширине 360 px.
- [x] Отчёт лежит в `docs/audits/a11y-YYYY-MM-DD.md`: страница, элемент, нарушение, серьёзность, предлагаемое исправление. Агент не правит исходники.
- [ ] Результаты автоматических проверок подтверждены вручную хотя бы на одной странице с клавиатуры и в тёмной теме.
- [x] Для каждой группы нарушений заведена история ([S10.13](../E10-product-features/S10.13.md) или новая) либо записано решение не чинить с причиной.

## Заметки

- Автоматические проверки находят только часть нарушений, поэтому ручная проверка в ACs обязательна.
- **Сделано 2026-11-17:** [docs/audits/a11y-2026-11-17.md](../../audits/a11y-2026-11-17.md), 4 группы находок (0 высоких, 2 средних). Скрипт по шаблонам и чтение, не Lighthouse или axe: в контейнере нет браузера.
- **Не выполнен AC про ручную проверку с клавиатуры** на живой странице (нужен браузер): остаётся владельцу. Статус ❌.
