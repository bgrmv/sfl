# S8.1 — Роли в интерфейсе

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S0.1](../E00-security-hotfix/S0.1.md)

**DESC:** Как администратор лиги, я хочу, чтобы интерфейс показывал действия по роли, чтобы модератор не видел управления ролями, а гость — кнопок редактирования.

**ACs:**

- [x] Роли `ADMIN`, `MODERATOR`, `USER`, `GUEST` имеют описанный набор прав в `docs/roles.md`.
- [x] Кнопки и страницы администрирования скрыты для ролей без прав. Права в любом случае проверяет сервер (guard и проверка ролей в Nest).
- [x] Роли `QA` и `TEST` удалены или описаны.

## Заметки

- **Сделано 2026-11-17:** [docs/roles.md](../../roles.md): таблица ролей «что может сейчас» и «что планируется», что видит интерфейс. Скрытие управления для ролей без прав уже было сделано: маршруты редактирования за `authGuard`, кнопки по `isAdmin()`, сервер проверяет всегда (матрица `access.test.ts`). `QA` и `TEST` описаны как зарезервированные и не используемые; из `EnumRole` не удалены, чтобы не ломать записи в коллекции `roles` прода до [S6.9](../E06-data-migration/S6.9.md).
- Отдельного UI для `MODERATOR` нет: сервер не даёт этой роли прав, пока не сделаны [S10.35](../E10-product-features/S10.35.md) и [S10.49](../E10-product-features/S10.49.md).
