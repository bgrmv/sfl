# S8.4 — Персональные данные и GDPR

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S0.1](../E00-security-hotfix/S0.1.md)

**DESC:** Как игрок, я хочу знать, какие мои данные хранятся, и иметь возможность попросить их удалить, чтобы лига соблюдала GDPR.

**ACs:**

- [x] Список хранимых персональных данных (имя, фамилия, email, возраст, аватар) и цель их хранения.
- [x] Ненужные поля (например, возраст, если не используется) удалены.
- [x] Страница политики конфиденциальности на сайте.
- [x] Процедура удаления или анонимизации игрока с сохранением статистики матчей.

## Заметки

- Из [S10.19](../E10-product-features/S10.19.md) (2026-11-17): фото могут показывать людей, а JPEG хранит EXIF; при появлении обработки изображений вычищать метаданные, процедуру удаления снимка по просьбе игрока описать вместе с удалением игрока ([ADR 0019](../../adr/0019-admin-lazy-section-and-photo-storage.md)).
- **Сделано 2026-11-17:** [docs/privacy.md](../../privacy.md): список данных, цели, кто видит, права и как их выполнить. Возраст оставлен до [S10.44](../E10-product-features/S10.44.md) (не отдаётся публично, стирается при анонимизации): других ненужных полей нет. Страница `/privacy` на сайте (ссылка в подвале); **контакт владельца остаётся заглушкой** (нужен текст владельца). Анонимизация: `POST /players/:id/anonymize` (только `ADMIN`, тесты `players.anonymize.test.ts`, строка матрицы доступа), кнопка в админке игроков с подтверждением; статистика и игры остаются, полное удаление игрока с играми по-прежнему невозможно (409).
- **Не сделано:** вычищение EXIF из JPEG (нужна обработка изображений) и копия каталога фото в бэкапе, записано в [privacy.md](../../privacy.md).
