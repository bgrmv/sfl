**ACs:**
- [ ] Список хранимых персональных данных (имя, фамилия, email, возраст, аватар) и цель их хранения.
- [ ] Ненужные поля (например, возраст, если не используется) удалены.
- [ ] Страница политики конфиденциальности на сайте.
- [ ] Процедура удаления или анонимизации игрока с сохранением статистики матчей.
