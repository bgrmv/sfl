# S8.2 — Защита входа от перебора

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S0.1](../E00-security-hotfix/S0.1.md)

**DESC:** Как пользователь, я хочу, чтобы мой пароль нельзя было подобрать перебором, чтобы аккаунт был в безопасности.

**ACs:**
- [ ] Лимит попыток входа на `POST /rest/auth/sign-in` по IP и по email (`@nestjs/throttler` или аналог). За прокси Caddy учитывается реальный IP клиента.
- [ ] Требования к паролю: минимальная длина и проверка по списку утёкших паролей (например, k-anonymity API Have I Been Pwned).
- [ ] При необходимости добавлена CAPTCHA на форму входа.
