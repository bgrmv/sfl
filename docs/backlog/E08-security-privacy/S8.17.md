# S8.17 — Выдача ссылок и ролей из админки

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S8.13](S8.13.md), [S8.9](S8.9.md)

**DESC:** Как администратор, я хочу создавать ссылки для подключения аккаунтов и назначать пользователям уровни доступа из админки, чтобы не пользоваться запросами к API и правкой базы.

**ACs:**

- [x] Раздел «Connect accounts»: выбор игрока без Google-аккаунта («Ник, Имя Фамилия»), создание ссылки на 1 день, ссылка показывается один раз с обратным отсчётом, «Copy link» и «Copy message», список ссылок с фильтром «All, Active, Used, Expired, Revoked» и отзывом.
- [x] `GET /auth/invitations` (только `ADMIN`): статус каждой ссылки и игроки с подключённым Google; без токена, email и Google `sub`.
- [x] Раздел «Users and access»: список аккаунтов (имя, ник, роли, подключён ли Google, без email), выдача и снятие ролей `ADMIN`, `MODERATOR`, `USER`; человек без роли имеет уровень гостя.
- [x] `GET /users` и `PATCH /users/:id/roles` только для `ADMIN`; строки в `access.test.ts`; нельзя снять роль `ADMIN` с себя и с последнего администратора; после смены роли сессии человека завершаются (`tokenVersion`).
- [x] Тесты сервера (`user-roles.test.ts`, `google-signin.test.ts`) и клиента (`admin-connect.page.spec.ts`, `admin-users.page.spec.ts`); `openapi.json` обновлён.

## Заметки

- Не сделано, остаётся в [S10.48](../E10-product-features/S10.48.md): вход по логину и паролю, QR и лист для печати, «Reset access», массовое создание, аватар, сводка за месяц.
- **Права модератора.** Владелец хочет, чтобы `MODERATOR` создавал матчи и одобрял комментарии. Комментарии он одобряет уже сейчас, подтверждает матчи тоже. Создание матчей модератором пока закрыто: оно связано с правилом двух подтверждений ([S10.35](../E10-product-features/S10.35.md)) и вводом матчей ([S10.49](../E10-product-features/S10.49.md)), решить там.
- Роль `GUEST` не хранится: это отсутствие роли или токена, поэтому «по умолчанию гость» означает пустой список ролей.
