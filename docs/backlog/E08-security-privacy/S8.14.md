# S8.14 — Уязвимость picomatch в dev-зависимостях ломает `pnpm check`

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** S · **Зависит от:** [S8.8](S8.8.md)

**DESC:** Как разработчик, я хочу, чтобы `pnpm check` проходил, а шаг `pnpm audit` оставался включённым, чтобы агент и хук снова могли доверять «зелёному» результату.

**ACs:**

- [x] Выяснено, какие пакеты тянут `picomatch <=4.0.7` (GHSA-fc5q-39xc-vjpf, ReDoS, high): по `pnpm audit` это `@angular/build` → `@vitejs/plugin-basic-ssl` → `vite`, всего 110 путей. Проверено, затрагивает ли это прод-код или только dev-инструменты.
- [ ] Когда выйдет исправленная версия `picomatch`, она закреплена через `overrides` в `pnpm-workspace.yaml` (или обновлён родительский пакет), `pnpm audit --audit-level high` проходит во всех пакетах workspace.
- [x] Пока патча нет: шаги `audit:*` добавлены в `KNOWN` в [scripts/check.mjs](../../../scripts/check.mjs) с причиной и ссылкой на эту историю, остальные шаги `pnpm check` проходят. Запись из `KNOWN` удалена после исправления.
- [x] `pnpm check` проходит целиком (шаги `audit:*` пропускаются через `KNOWN`).

## Заметки

- **Найдено 2026-11-18** при закрытии [S6.1](../E06-data-migration/S6.1.md). На чистом дереве (без правок) `pnpm audit --audit-level high` падает так же: к S6.1 это не относится. В отчёте «Patched versions: `<0.0.0`», то есть исправления пока нет.
- **Сделано 2026-11-18.** `picomatch` 4.0.7 стоит только в `devDependencies` (путь `lint-staged > picomatch` и цепочка Angular/vite); `pnpm audit --prod --audit-level high` чист, в прод-сборку пакет не попадает. Последняя версия в реестре — 4.0.7, исправления нет. Четыре шага `audit:*` занесены в `KNOWN` ([scripts/check.mjs](../../../scripts/check.mjs)), остальные шаги `pnpm check` зелёные.
- **Статус остаётся ❌:** второй AC ждёт патча. Что сделать, когда `picomatch` обновится: `pnpm audit --audit-level high` (или `pnpm update picomatch -r`), при необходимости `overrides` в `pnpm-workspace.yaml`, удалить `PICOMATCH` и четыре строки из `KNOWN`, отметить AC, поменять ❌ на ✅.
