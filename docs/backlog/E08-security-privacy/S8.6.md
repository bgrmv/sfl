# S8.6 — Безопасные ссылки и изображения на клиенте

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P4 · **Размер:** S · **Зависит от:** [S7.4](../E07-vps-hosting/S7.4.md)

**DESC:** Как пользователь, я хочу, чтобы ссылки и изображения из данных лиги не могли выполнить вредный код, чтобы сайт был безопасен.

**ACs:**
- [ ] Поле `link` матча проверяется: разрешены только `https://`.
- [ ] Изображения выводятся через `NgOptimizedImage` (`ngSrc`). `innerHTML` с данными из базы не используется или проходит санитизацию.
- [ ] Закрыт пункт «ngSrc, ngHref — security directives» из TODO в README.
