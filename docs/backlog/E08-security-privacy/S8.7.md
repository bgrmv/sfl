# S8.7 — Современное хеширование паролей

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** S · **Зависит от:** [S4.3](../E04-migration-design/S4.3.md), [S2.4](../E02-tests-ci/S2.4.md)

**DESC:** Как пользователь, я хочу, чтобы даже при утечке базы мой пароль нельзя было быстро подобрать, и чтобы для этого мне не пришлось ничего делать.

**ACs:**
- [ ] Новые и изменённые пароли хешируются argon2id (или bcrypt, по решению [S4.3](../E04-migration-design/S4.3.md)) с солью.
- [ ] При успешном входе с паролем в старом SHA-512 хеш сразу пересчитывается в новый алгоритм.
- [ ] У пользователя хранится признак алгоритма хеша. Видно, сколько аккаунтов ещё не переведено.
- [ ] Тесты: вход со старым хешем переводит его в новый; вход с новым хешем работает; неверный пароль отклоняется в обоих случаях.
- [ ] По истечении срока из [S4.3](../E04-migration-design/S4.3.md) оставшиеся SHA-512 хеши удаляются отдельным скриптом.
