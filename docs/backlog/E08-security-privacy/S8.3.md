# S8.3 — Проверка на секреты и уязвимости в CI

**Эпик:** 8 — Безопасность и персональные данные · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P4 · **Размер:** S · **Зависит от:** [S2.1](../E02-tests-ci/S2.1.md), [S8.8](S8.8.md)

**DESC:** Как разработчик, я хочу, чтобы CI ловил секреты и уязвимые зависимости, чтобы история с `_backups` и passphrase не повторилась.

**ACs:**
- [ ] В CI запускается сканер секретов (например, gitleaks). Найденный секрет валит сборку.
- [ ] Включены GitHub secret scanning и Dependabot alerts.
- [ ] `pnpm audit` с уровнем high валит CI.
