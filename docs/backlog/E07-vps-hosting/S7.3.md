# S7.3 — Домен и HTTPS через Caddy

**Эпик:** 7 — Хостинг на VPS · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S7.2](../E07-vps-hosting/S7.2.md), [S7.9](../E07-vps-hosting/S7.9.md), ответ на открытый вопрос 5

**DESC:** Как пользователь, я хочу заходить по прежнему адресу лиги по HTTPS, чтобы не узнавать новый адрес.

**ACs:**
- [ ] В репозитории есть `deploy/caddy/sfl.caddy` с маршрутами SFL для общего edge-прокси ([S7.9](../E07-vps-hosting/S7.9.md)): прод-домен ведёт на `sfl-prod-app`, staging-поддомен — на `sfl-staging-app` (по DNS-имени сервиса в сети `edge`).
- [ ] Сертификаты выпускаются и продлеваются автоматически. Данные Caddy лежат в volume edge-прокси.
- [ ] TTL DNS заранее снижен для быстрого переключения и отката.
- [ ] Редирект с `www` на основной домен (или наоборот) и с HTTP на HTTPS.
- [ ] Staging закрыт от поисковиков (`X-Robots-Tag: noindex`) и, при необходимости, базовой авторизацией.
- [ ] Websocket-соединения проходят через прокси (проверено, когда появится [S10.10](../E10-product-features/S10.10.md)).
