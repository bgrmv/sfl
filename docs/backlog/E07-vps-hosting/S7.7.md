# S7.7 — Базовая защита VPS

**Эпик:** 7 — Хостинг на VPS · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** S · **Зависит от:** —

**DESC:** Как владелец проекта, я хочу, чтобы сервер был закрыт от типовых атак и обновлялся сам, чтобы не тратить время на его обслуживание.

**ACs:**
- [ ] Вход по ssh только по ключу. Вход под root и по паролю запрещён.
- [ ] Firewall (на уровне провайдера или `ufw`) открывает только 22, 80, 443.
- [ ] Включены автоматические обновления безопасности ОС.
- [ ] Docker и compose установлены из официального репозитория. У каждого проекта свой deploy-пользователь без sudo с правами записи только в свою папку `/opt/<проект>/` (для SFL — `/opt/sfl/`).
- [ ] Ротация логов Docker настроена глобально (`/etc/docker/daemon.json`), чтобы ни один проект не заполнил диск.
- [ ] Настройка сервера описана скриптом или пошаговым runbook в `docs/runbooks/vps-setup.md`. Новый сервер поднимается по нему за час.
