# S7.1 — Один Docker-образ приложения

**Эпик:** 7 — Хостинг на VPS · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S1.4](../E01-dependency-upgrades/S1.4.md), [S3.6](../E03-architecture/S3.6.md)

**DESC:** Как разработчик, я хочу собирать клиент и сервер в один Docker-образ, чтобы деплоить одну вещь и одинаково запускать её локально, на staging и в проде.

**ACs:**
- [ ] `Dockerfile` в корне: multi-stage сборка. Отдельные стадии собирают Angular (browser и server бандлы) и Nest, финальная стадия содержит только runtime-зависимости.
- [ ] Финальный образ основан на slim-образе Node той же версии, что в [S1.2](../E01-dependency-upgrades/S1.2.md), и запускается не от root.
- [ ] `.dockerignore` исключает `node_modules`, `.git`, `_backups`, локальные `.env`.
- [ ] Образ стартует с переменными окружения из `.env.example` и отвечает на `GET /rest/health`.
- [ ] Хешированные файлы клиента отдаются с долгим кешированием, HTML — без кеша.
- [ ] Конфиги Azure Static Web Apps (`client/staticwebapp.config.json` и корневой) удалены после cutover.
