# S7.13 — Тест: неизвестный `/rest/*` отвечает JSON 404

**Эпик:** 7 — Хостинг на VPS · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** S · **Зависит от:** [S7.1](S7.1.md)

**DESC:** Как разработчик, я хочу, чтобы раздача SPA из Nest не перехватывала маршруты API, чтобы клиент получал JSON-ошибку, а не `index.html`.

**ACs:**

- [x] API-тест в `server-nest/test/api/`: запрос неизвестного `/rest/...` даёт `404` и JSON формата ошибок ([docs/PROJECT.md](../../PROJECT.md), раздел 5.2), а не HTML.
- [x] Тест проверяет и обратное: путь клиента (например `/players/1`) отдаёт `index.html`, когда раздаётся собранная статика.
- [x] Тест падает, если убрать `exclude: ['/rest/{*any}']` из `ServeStaticModule` в [app.module.ts](../../../server-nest/src/app.module.ts).
