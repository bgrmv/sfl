**DESC:** Как владелец, я хочу закрыть мелкие хвосты настройки, чтобы сервер и секреты были в порядке.

**ACs:**

- [ ] Владелец удалил `~/.ssh/sfl-deploy` и `sfl-deploy.pub` в dev-container (копия приватного ключа лежит только в GitHub Secret `DEPLOY_SSH_KEY`).
- [ ] Сервер перезагружен (`reboot`) после обновления ядра, `docker compose ps` в `/opt/edge` и `/opt/sfl/staging` показывает работающие контейнеры.

- [ ] В строку для `/opt/edge/.env` вписана почта `ACME_EMAIL` (по желанию) и проверено, что Caddy её видит.
- [ ] Пуш воркфлоу `run-name` проверен: в списке Actions запуск показывает `Deploy → staging: …`.
- [ ] Закрытые видимые людям изменения добавлены в `docs/releases/NEXT.md`, если владелец решит, что деплой нужно показать в release notes.
