# S2.1 — CI для каждого PR

**Эпик:** 2 — Тесты и CI · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P4 · **Размер:** M · **Зависит от:** [S1.2](../E01-dependency-upgrades/S1.2.md), [S2.8](../E02-tests-ci/S2.8.md)

**DESC:** Как разработчик, я хочу, чтобы каждый PR автоматически проходил линт, проверку типов, тесты и сборку, чтобы ошибки находились до слияния.

**ACs:**
- [ ] Workflow `ci.yml` запускается на каждый PR в `main`.
- [ ] CI запускает ту же команду `pnpm check` ([S2.8](S2.8.md)), а не дублирует список шагов: `pnpm install --frozen-lockfile`, затем проверки по каждому пакету.
- [ ] Используется кеш pnpm.
- [ ] Клиентские и серверные тесты запускаются в CI в headless-режиме (перенесено из [S2.5](S2.5.md)).
- [ ] CI берёт версии Node и pnpm из `.nvmrc` и `packageManager`, а не задаёт их отдельно (перенесено из [S1.2](../E01-dependency-upgrades/S1.2.md)).
- [ ] В настройках репозитория включена защита `main`: слияние только при зелёном CI.
- [ ] Деплой-workflow запускается только после успешного CI.
