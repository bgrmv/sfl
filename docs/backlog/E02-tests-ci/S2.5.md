# S2.5 — Перевести клиентские тесты на поддерживаемый раннер

**Эпик:** 2 — Тесты и CI · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** M · **Зависит от:** [S1.4](../E01-dependency-upgrades/S1.4.md)

**DESC:** Как разработчик, я хочу быстрые клиентские тесты на поддерживаемом раннере, чтобы их удобно было писать и запускать в CI без браузера.

**ACs:**
- [ ] Karma и Jasmine заменены раннером, который официально поддерживает актуальный Angular (например, Vitest).
- [ ] Существующие spec-файлы (около восьми) переписаны и проходят.
- [ ] Добавлены тесты для `GamesStore`, `GameService`, `HttpService`, `jwtInterceptor`.
- [ ] Тесты запускаются в CI в headless-режиме.
