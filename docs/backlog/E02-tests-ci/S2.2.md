# S2.2 — Golden-master тесты расчёта статистики

**Эпик:** 2 — Тесты и CI · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** L · **Зависит от:** [S11.2](../E11-dx-docs/S11.2.md)

**DESC:** Как разработчик, я хочу тесты, которые сравнивают расчёт статистики с реальными прод-значениями, чтобы при рефакторинге, обновлениях и переездах цифры игроков не изменились незаметно.

**ACs:**
- [ ] Из прода снят анонимизированный снапшот: все матчи и сохранённые `metadata` игроков и матчей.
- [ ] Тест берёт матчи снапшота, считает метаданные текущим кодом и сравнивает с сохранёнными `byGame`, `bySeason`, `byCareer` для каждого игрока, включая обе рейтинговые системы (ancient и positional).
- [ ] Расхождения выводятся по игроку, сезону и полю. Известные расхождения (например, из-за старых ошибок в данных) зафиксированы в файле исключений с объяснением.
- [ ] Тест запускается в CI. Снапшот хранится вне публичного репозитория или достаточно анонимизирован.
