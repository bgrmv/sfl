- [ ] Матрица доступа: каждый изменяющий маршрут без токена — `401`, с токеном — успех.
- [ ] CRUD-сценарии для матча и игрока, включая невалидное тело (`400`).
- [ ] Шаблонный `test/app.e2e-spec.ts` заменён рабочими тестами.
- [ ] Тесты запускаются в CI ([S2.1](../E02-tests-ci/S2.1.md)) на каждый PR.
