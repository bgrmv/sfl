# S2.7 — Отчёт о покрытии и пороги

**Эпик:** 2 — Тесты и CI · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S2.1](../E02-tests-ci/S2.1.md)

**DESC:** Как разработчик, я хочу видеть покрытие в каждом PR, чтобы оно не падало со временем.

**ACs:**
- [ ] Отчёт о покрытии публикуется в CI для клиента и бэкенда.
- [ ] Порог: доменная логика ≥ 80%, общий — не ниже текущего значения.
- [ ] Падение покрытия ниже порога валит CI.
