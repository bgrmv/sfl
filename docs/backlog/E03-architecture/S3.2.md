# S3.2 — pnpm workspace и общие типы

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** M · **Зависит от:** [S1.2](../E01-dependency-upgrades/S1.2.md)

**DESC:** Как разработчик, я хочу один workspace с общими типами для клиента и бэкенда, чтобы не дублировать интерфейсы вроде `IGameDTO` и не расходиться в формате данных.

**ACs:**
- [ ] В корне `pnpm-workspace.yaml` с пакетами `client`, `server-nest` (пока нужен), `packages/domain`, `packages/types`.
- [ ] Типы игры, игрока, команды, статистики объявлены один раз в `packages/types`.
- [ ] Клиент и бэкенд импортируют их оттуда. Дублирующиеся интерфейсы удалены.
- [ ] Один `pnpm install` в корне ставит всё. CI обновлён.
