# S3.4 — Единый формат ответов API

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S2.4](../E02-tests-ci/S2.4.md)

**DESC:** Как разработчик клиента, я хочу, чтобы все ответы API имели один формат, чтобы обрабатывать данные и ошибки одинаково.

**ACs:**
- [ ] Контроллеры возвращают значения, а не вызывают `res.json(...)` через `@Res()`.
- [ ] Формат ответа `{ data }` для успеха и `{ error: { code, message, issues? } }` для ошибок (задача `TResponse` из README).
- [ ] Глобальный фильтр исключений формирует ошибки в этом формате.
- [ ] Клиентские сервисы обновлены.
