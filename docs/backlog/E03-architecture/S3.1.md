# S3.1 — Вынести доменную логику в независимый модуль

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** L · **Зависит от:** [S2.2](../E02-tests-ci/S2.2.md), [S2.3](../E02-tests-ci/S2.3.md)

**DESC:** Как разработчик, я хочу, чтобы расчёт статистики и рейтингов был чистым TypeScript без зависимостей от NestJS и Mongoose, чтобы его можно было перенести в Edge Functions или использовать на клиенте.

**ACs:**
- [ ] Расчёт метаданных игрока и матча находится в пакете `packages/domain` и экспортирует чистые функции: на вход матчи, на выход метаданные.
- [ ] В пакете нет импортов `@nestjs/*`, `mongoose`, `@angular/*`.
- [ ] Golden-master тесты ([S2.2](../E02-tests-ci/S2.2.md)) проходят на новом модуле.
- [ ] Сервер (пока он есть) использует этот пакет вместо своих утилит.
