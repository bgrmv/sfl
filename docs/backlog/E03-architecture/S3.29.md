# S3.29 — Шапка игрока и карточка рейтинга: вынести в общие блоки клиента

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S3.28](S3.28.md)

**DESC:** Как разработчик, я хочу, чтобы шапка игрока и карточка рейтинга были общими блоками, а не копиями разметки на четырёх страницах, чтобы правка дизайна менялась везде сразу.

Основание: остаток [S3.28](S3.28.md). Макет: доска `PlayerChip` в «SFL UI Kit» (секция 8, [PlayerChip.dc.html](../../design/canvas/PlayerChip.dc.html)), раздел `3 · Next blocks to extract (proposal)`.

**ACs:**

- [x] Блок `Player header` из макета: крупный аватар, заголовок, строка фактов, необязательный бейдж или кнопка справа; размеры аватара 56 и 96 px. Лежит в `entities/player/ui`, строится на `PlayerChipComponent` или рядом с ним. Используется в `player-board` (96 px), `compare-people`, `profile` («My player») и `connect` («This is your player»).
- [x] Блок `Rating card` из макета: строка игрока слева, главное число справа, строка деталей под ними, левая полоса акцента. Используется в `players-board` (вид Cards) и `captains-board` (вид Cards). Бейдж «C» и заголовок `k-head` передаются слотами.
- [x] Данные двух сущностей блоки получают входами от страницы, без кросс-импортов слоёв ([ADR 0016](../../adr/0016-client-fsd-layers-and-cross-imports.md), п. 5 и 7).
- [x] Тест на каждый блок (рендер, пустые значения, слоты, ссылка); сначала тест, потом код ([ADR 0013](../../adr/0013-tests-first-then-domain-then-local.md)).
- [x] Копии разметки на страницах удалены, внешний вид сверен с доской; `pnpm check` проходит.

## Заметки

- Создана 2026-11-17 при закрытии [S3.28](S3.28.md).
- **Сделано 2026-11-17:** `PlayerHeaderComponent` (`sfl-player-header`: входы `name`, `size` 56/96, `accent`, `level` 1/2; слоты `header-eyebrow`, по умолчанию строка фактов, `header-aside`) и `RatingCardComponent` (`sfl-rating-card`: входы `name`, `value`, `playerId`, `rank`; слот `card-badge`, остальное содержимое под строкой игрока) лежат в `entities/player/ui`. Карточка рейтинга больше не ссылка целиком: ссылка на игрока в имени (`PlayerChip`), как на доске; на странице игроков это снимает вложенные ссылки.
- Внешний вид сверен по разметке и токенам доски, в браузере не смотрен: проверьте глазами `/players` (Cards), `/captains`, страницу игрока, `/compare`, `/profile`, `/connect`.
