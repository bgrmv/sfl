# S3.8 — Границы слоёв клиента проверяются линтером

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S1.6](../E01-dependency-upgrades/S1.6.md)

**DESC:** Как разработчик, я хочу, чтобы линтер запрещал импорты против слоёв (например, из `shared` в `entities`), чтобы структура FSD не размывалась.

**ACs:**
- [ ] Настроено правило границ (например, `eslint-plugin-boundaries`): `pages → widgets → features → entities → shared`.
- [ ] Импорт в обратную сторону даёт ошибку линта.
- [ ] Существующие нарушения исправлены.
