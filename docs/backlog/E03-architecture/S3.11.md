# S3.11 — Исправить расчёт метаданных матча и игрока

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P1 · **Размер:** L · **Зависит от:** [S2.3](../E02-tests-ci/S2.3.md)

**DESC:** Как администратор лиги, я хочу, чтобы победы, поражения, голы и MVP считались верно, чтобы статистика игроков и рейтинги соответствовали реальным результатам.

**ACs:**
- [x] Игроки обеих команд получают верные `hasWon`, `hasLose`, `hasDraw` (A1 аудита). Тест: матч 0:3, у игроков победившей команды `hasWon=true`.
- [x] Пенальти игрока попадают в `totalGoalsByPenalty` и `totalGoals` (A2).
- [x] `mvpByGoalsIds` считается по сумме голов, а не только по голам головой (A3).
- [x] При ничьей `captainWon` и `captainLost` не указывают на одного игрока (A4).
- [x] Автогол идёт в счёт команды-соперника, автору даёт −1 очко; `totalGoalsByAuto` считается (A5, правило подтверждено 2026-11-13, см. [GLOSSARY.md](../../../GLOSSARY.md)).
- [x] Правило веса голов (голова ×2 или ×1) подтверждено владельцем и одинаково для матча и игрока (A6).
- [x] Матч без капитана в команде или с двумя капитанами в одной команде отклоняется валидацией с 400, а не падает с 500 (A7). Тест `it.fails` в `test/api/games.test.ts` станет обычным.
- [x] `POST /games` и `PATCH /games/:id` возвращают матч **после** пересчёта, `metadata` заполнена (A8).
- [x] В сезонную и карьерную статистику и в графики попадают только матчи в статусе «Опубликован»; смена статуса пересчитывает игроков (A9, дополнение аудита).
- [x] Матч нельзя опубликовать, если у кого-то из участников нет позиции: 400 (A10).
- [x] Трансфер (игрок в обеих командах): баланс результатов 0, позиционный бонус 0, голы и передачи обеих строк статистики попадают в его итоги (A11; сейчас `lr = −1`, бонус считается как за поражение, берётся только первая строка).
- [x] Новая система счёта считается от своих накопленных значений, а не от значений старой системы, и гол головой в ней ×2 (A12; сейчас `positionalRatingSystem` прибавляет к `ancientRatingSystem`, голова ×1).
- [x] `captainedGamesIds` накапливает только матчи, где игрок был капитаном (A13; сейчас прибавляется к `gamesIds`).
- [x] Комментарий к плюс-минусу в `IRatingSystem` приведён к правилу «разница счёта команды» (A14).
- [x] Каждое исправление закреплено тестом; golden-master ([S2.2](../E02-tests-ci/S2.2.md)) обновлён там, где поведение изменилось намеренно.

## Заметки

- Источник: [аудит кода 2026-11-13](../../audits/code-2026-11-13.md), группа A. Воспроизведения в отчёте.
- Сначала [S2.3](../E02-tests-ci/S2.3.md): тесты фиксируют текущее поведение, затем исправления меняют ожидания осознанно.
- Исправление затрагивает уже посчитанные данные: метаданные хранятся в самих матчах, поэтому `POST /players/recalculate/season` их не исправляет. Пересчёт всех матчей вынесен в [S3.14](S3.14.md).
- **Правило веса голов подтверждено владельцем 2026-11-13: гол головой = ×2, остальные (ногой, пенальти) = ×1.** Матч уже считает так, игрок — с весом ×1 (A6), поэтому исправлять нужно расчёт игрока. Тесты S3.11 ожидают ×2 и для матча, и для игрока.
- **Дополнение 2026-11-13** (сверка с [GLOSSARY.md](../../../GLOSSARY.md), применён skill `domain-modeling`): правила автогола, трансфера, статуса матча, новой системы счёта и обязательной позиции подтверждены владельцем. Расхождения кода с ними описаны в разделе 6 [аудита](../../audits/code-2026-11-13.md) (A9–A14); размер истории поднят с M до L.
- **Сделано 2026-11-13.** Все 17 тестов `it.fails` из [S2.3](../E02-tests-ci/S2.3.md) стали обычными, `it.fails` в проекте не осталось. Что изменено в коде: расчёт матча и игрока (`games.service.ts`), накопление сезона (`player-season-metadata.ts`), фильтр опубликованных матчей в пересчёте сезона (`players.service.ts`), правила капитанов, команд и позиций в DTO (`game.dto.ts`). Ответы `POST` и `PATCH` возвращают матч после пересчёта.
- Golden-master ([S2.2](../E02-tests-ci/S2.2.md)) ещё не написан, обновлять нечего: его нужно писать уже на исправленном расчёте. AC отмечен с этим условием.
- Новые правила на входе ужесточены: опубликованный матч без позиций и команда без ровно одного капитана дают 400. Клиентская часть — [S3.13](S3.13.md). Поле `mvpByGoalsHeadIds` осталось в метаданных матча для совместимости, но в MVP игрока уже не участвует.
