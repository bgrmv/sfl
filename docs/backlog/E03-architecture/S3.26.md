# S3.26 — Steiger как проверка структуры FSD

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** S · **Зависит от:** [S3.8](S3.8.md)

**DESC:** Как разработчик, я хочу, чтобы официальный линтер FSD Steiger проверял структуру слайсов (лишние и одиночные слайсы, имена файлов по роли), потому что правила импортов из [S3.8](S3.8.md) этого не видят.

**ACs:**

- [x] В истории выбрана версия Steiger и плагин (`@feature-sliced/steiger-plugin`); пробный прогон по `client/src` показал, что он читает алиасы `@entities/*`, `@features/*`, `@pages/*`, `@shared/*`.
- [x] Правила импортов Steiger не дублируют ESLint из S3.8 (отключены или совпадают), конфиг `steiger.config.ts` с причинами отключённых правил.
- [x] Шаг `client:fsd` добавлен в `pnpm check`; найденные нарушения исправлены или занесены в исключения с причиной (мёртвые слайсы `captain-to-add`, `captains-selection`, `games-table` решаются вместе с [S10.8](../E10-product-features/S10.8.md)).
- [x] `AGENT.md` и [ADR 0016](../../adr/0016-client-fsd-layers-and-cross-imports.md) упоминают проверку.

## Заметки

- Решение владельца 2026-11-16 (вопрос «Steiger или свой линтер»): пользовательские правила ESLint из S3.8 остаются, Steiger добавляется как дополнение для структуры.
- **Сделано 2026-11-17:** `steiger` 0.10.0 и `@feature-sliced/steiger-plugin` 0.8.2 (dev-зависимости клиента), конфиг `client/steiger.config.mjs` (`.mjs`, чтобы не требовать `"type": "module"`), шаг `client:fsd` в `scripts/check.mjs`. Пробный прогон читает алиасы `@entities/*`, `@shared/*` и т.д.
- Первый прогон дал 96 находок; отключены с причинами в конфиге: `public-api`, `no-public-api-sidestep` и `segments-by-purpose` для `shared` (сегменты импортируются по файлам, имена `constants`, `pipes`, `store`, `utils` старые); `insignificant-slice` для мёртвых слайсов ([S10.8](../E10-product-features/S10.8.md)) и слайсов с одним потребителем. Импортные правила ESLint не дублируются: для слайсов `no-public-api-sidestep` Steiger не нашёл нарушений.
