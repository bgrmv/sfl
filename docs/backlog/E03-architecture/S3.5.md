# S3.5 — Атомарное сохранение матча и пересчёта [если NestJS остаётся]

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S3.3](../E03-architecture/S3.3.md)

**DESC:** Как администратор лиги, я хочу, чтобы сохранение матча и пересчёт статистики происходили целиком или не происходили вовсе, чтобы данные не оставались наполовину обновлёнными.

**ACs:**
- [ ] Сохранение матча и обновление метаданных игроков выполняются в одной транзакции MongoDB.
- [ ] Закомментированный код в `players.transactions.ts` удалён или заменён рабочим.
- [ ] Тест: при ошибке пересчёта матч не сохраняется.
- [ ] При варианте A требование переносится в [S5.5](../E05-supabase-backend/S5.5.md) (транзакция Postgres).
