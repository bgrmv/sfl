# S3.3 — Разорвать цикл games ↔ players [если NestJS остаётся]

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S3.1](../E03-architecture/S3.1.md)

**DESC:** Как разработчик, я хочу убрать циклическую зависимость между модулями матчей и игроков, чтобы модули можно было менять и тестировать отдельно.

**ACs:**
- [ ] `GamesModule` не использует `forwardRef(() => PlayersModule)`.
- [ ] `PlayersService` не указан в провайдерах `GamesModule`, существует один экземпляр.
- [ ] Пересчёт метаданных вызывается через отдельный сервис или событие «матч опубликован».
