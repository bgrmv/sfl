# S3.30 — Малые формы клиента на signal forms

**Эпик:** 3 — Улучшение архитектуры · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S3.16](S3.16.md)

**DESC:** Как разработчик, я хочу перевести малые формы клиента на signal forms по образцу пилота, чтобы правила проверки жили в `@sfl/schemas`, а не дублировались руками.

Основание: итог пилота [S3.16](S3.16.md), диалог игрока (`player-edit-dialog`) работает на `form()` и `validateStandardSchema`.

**ACs:**

- [ ] Вход (`sign-in`): форма на `form()`, правила `signInSchema` из `@sfl/schemas`; сообщения об ошибках входа остаются как сейчас.
- [ ] Диалог создания игрока (`create-player-dialog`): форма на `form()`, схема формы в `@sfl/schemas` рядом с `playerEditFormSchema`; вспомогательные типы `FormControls` и `SetRequired` из `src/types.d.ts` удалены, если больше не нужны.
- [ ] Форма новой команды матча (`game-team-create`): то же.
- [ ] Тесты каждой формы: валидные и невалидные значения, отправка, сообщения; сначала тест ([ADR 0013](../../adr/0013-tests-first-then-domain-then-local.md)).
- [ ] `pnpm check` проходит.
