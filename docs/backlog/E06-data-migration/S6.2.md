# S6.2 — ETL-скрипт переноса

**Эпик:** 6 — Миграция данных MongoDB → Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** L · **Зависит от:** [S4.2](../E04-migration-design/S4.2.md), [S4.4](../E04-migration-design/S4.4.md), [S5.2](../E05-supabase-backend/S5.2.md)

**DESC:** Как разработчик, я хочу повторяемый скрипт переноса из MongoDB в Postgres, чтобы прогонять миграцию сколько угодно раз до финального переключения.

**ACs:**
- [ ] Скрипт в `tools/migrate/` читает из MongoDB, преобразует и пишет в Postgres.
- [ ] Порядок: роли → пользователи и профили → игроки → команды → матчи → команды матча → статистика.
- [ ] `ObjectId` переводятся в UUID. Соответствие сохраняется в `legacy_id`.
- [ ] Все проблемы из [S4.4](../E04-migration-design/S4.4.md) обрабатываются по принятому решению. Каждая отброшенная запись попадает в отчёт.
- [ ] Скрипт идемпотентен: повторный запуск на пустую или заполненную базу даёт тот же результат.
- [ ] Запись в Postgres выполняется в одной транзакции. При ошибке ничего не записано.
