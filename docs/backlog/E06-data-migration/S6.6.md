# S6.6 — Репетиции миграции на staging [если переходим на Postgres]

**Эпик:** 6 — Миграция данных и переключение · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S6.2](../E06-data-migration/S6.2.md), [S6.4](../E06-data-migration/S6.4.md)

**DESC:** Как разработчик, я хочу прогнать полную миграцию на копии прод-данных минимум два раза, чтобы в день переключения не было сюрпризов.

**ACs:**
- [ ] Две полные репетиции на staging с последним бэкапом прода.
- [ ] Записано время каждого шага. Итоговое время укладывается в окно заморозки.
- [ ] После каждой репетиции отчёт сверки ([S6.4](../E06-data-migration/S6.4.md)) без необъяснённых расхождений.
- [ ] E2E-тесты ([S2.6](../E02-tests-ci/S2.6.md)) проходят на staging с перенесёнными данными.
