# S6.3 — Старые ссылки продолжают работать [если переходим на Postgres]

**Эпик:** 6 — Миграция данных и переключение · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S6.2](../E06-data-migration/S6.2.md)

**DESC:** Как пользователь, я хочу, чтобы ссылки на матчи и игроков, которые я отправлял в чат, открывались после переезда, чтобы не искать их заново.

**ACs:**
- [ ] Маршрут клиента с `ObjectId` (24 hex-символа) находит запись по `legacy_id` и перенаправляет на новый адрес.
- [ ] Проверено на выборке реальных ссылок из чата лиги.
