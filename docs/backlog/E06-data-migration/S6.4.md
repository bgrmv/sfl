# S6.4 — Сверка данных после переноса [если переходим на Postgres]

**Эпик:** 6 — Миграция данных и переключение · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S6.2](../E06-data-migration/S6.2.md), [S3.1](../E03-architecture/S3.1.md)

**DESC:** Как администратор лиги, я хочу доказательство, что после переноса все матчи, голы и рейтинги совпадают, чтобы доверять новой системе.

**ACs:**
- [ ] Автоматический отчёт сравнивает:
  - число записей по каждой сущности;
  - сумму голов, пасов, MVP по сезону и по игроку;
  - пересчитанные в Postgres `bySeason` и `byCareer` каждого игрока с сохранёнными значениями в MongoDB;
  - результаты графиков с текущим API `/rest/charts`.
- [ ] Все расхождения объяснены или исправлены. Отчёт прикладывается к решению о cutover.
- [ ] Администратор лиги вручную проверил 5–10 знакомых игроков и последние матчи.
