## Заметки

- **Сделано 2026-11-15 (без доступа к проду).** Скрипт [scripts/mongo-backup.mjs](../../../scripts/mongo-backup.mjs) (`pnpm backup:prod`, `backup:verify`, `backup:status`), установка `mongodump` и `age` ([install-backup-tools.sh](../../../.devcontainer/install-backup-tools.sh)), runbook [mongo-backup.md](../../runbooks/mongo-backup.md). Вся цепочка (дамп → шифрование → расшифровка → восстановление → сверка) прогнана на локальной базе: 6 коллекций, числа совпали.
- **Осталось владельцу:** создать ключ `age`, выполнить `pnpm backup:prod` с `SFL_PROD_URI` прода, скопировать архив во внешнее хранилище, выполнить `pnpm backup:verify` и отметить первые два AC.
- **Отступление от AC.** Архив по умолчанию пишется в `_backups/prod/` (в `.gitignore`, на диске хоста). «Вне репозитория» обеспечивает копия во внешнее хранилище из runbook.
- `pnpm start:dev` только предупреждает об отсутствии свежего бэкапа и не блокирует запуск.
- **Выполнено владельцем 2026-11-18.** База прода называется `prod` (не `sfl`): первый запуск с `sfl` дал пустой архив, его удалили; имя базы задаётся `SFL_PROD_DB`. Бэкап `prod-2026-11-18-0855`: games 16, players 232, roles 2, teams 2, users 233. `pnpm backup:verify`: все 5 коллекций совпали с манифестом.
