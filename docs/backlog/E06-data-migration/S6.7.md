# S6.7 — Переключение с Azure на MVPS и план отката

**Эпик:** 6 — Миграция данных и переключение · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S7.3](../E07-vps-hosting/S7.3.md), [S7.5](../E07-vps-hosting/S7.5.md), [S7.6](../E07-vps-hosting/S7.6.md), [S7.8](../E07-vps-hosting/S7.8.md), [S2.6](../E02-tests-ci/S2.6.md)

**DESC:** Как администратор лиги, я хочу перевести сайт с Azure на MVPS по понятному плану с точкой отката, чтобы лига ни дня не осталась без сайта.

**ACs:**
- [ ] Новое приложение (целевая архитектура: Nest + Angular SSR) работает на MVPS с той же базой MongoDB Atlas, что и прод на Azure. Данные не переносятся, переключается только трафик.
- [ ] IP MVPS добавлен в IP Access List Atlas. Пользователь базы для MVPS отдельный, с минимально нужными правами.
- [ ] Runbook: объявление, свежий бэкап ([S6.1](../E06-data-migration/S6.1.md)), переключение DNS, smoke-тесты, объявление о завершении.
- [ ] Пока работают оба приложения, писать в базу можно только через одно из них (на время переключения запись в Azure-версии закрыта или заморожена).
- [ ] Критерии и шаги отката: откат — это возврат DNS на Azure, база общая. Azure-версия остаётся в рабочем состоянии не меньше двух недель.
- [ ] Переключение выполнено в согласованное окно, отчёт приложен.
