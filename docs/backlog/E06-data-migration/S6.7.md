# S6.7 — План переключения и отката

**Эпик:** 6 — Миграция данных MongoDB → Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S6.6](../E06-data-migration/S6.6.md), [S7.3](../E07-netlify-hosting/S7.3.md)

**DESC:** Как администратор лиги, я хочу понятный план переключения с точкой отката, чтобы лига не осталась без сайта.

**ACs:**
- [ ] Runbook: объявление, заморозка записи, финальный бэкап, миграция, сверка, переключение DNS, smoke-тесты, объявление о завершении.
- [ ] Текущее приложение умеет работать в режиме «только чтение» на время заморозки.
- [ ] Определены критерии отката и шаги отката. MongoDB и Azure остаются в режиме чтения не меньше двух недель.
- [ ] Переключение выполнено в согласованное окно, отчёт приложен.
