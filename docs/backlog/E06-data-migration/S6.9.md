# S6.9 — Перенос MongoDB из Atlas в compose на MVPS

**Эпик:** 6 — Миграция данных и переключение · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S6.8](../E06-data-migration/S6.8.md), [S7.8](../E07-vps-hosting/S7.8.md)

**DESC:** Как владелец проекта, я хочу держать базу на своём сервере рядом с приложением, чтобы не зависеть от лимитов бесплатного Atlas и иметь всё в одном месте.

**ACs:**
- [ ] В `docker-compose.yml` добавлен сервис `mongodb`: версия как в Atlas (или совместимая), именованный volume, single-node replica set (нужен для транзакций из [S3.5](../E03-architecture/S3.5.md)), лимит кеша и памяти по [S7.2](../E07-vps-hosting/S7.2.md). Порт наружу не публикуется.
- [ ] Репетиция на staging: `mongodump` из Atlas → `mongorestore` в compose. Число документов в каждой коллекции и индексы совпадают, приложение работает на локальной базе.
- [ ] Прод: короткая заморозка записи, финальный `mongodump`, `mongorestore`, смена `DATABASE_URL`, перезапуск `app`, smoke-тесты. Время шагов записано в runbook.
- [ ] Ночные бэкапы ([S7.8](../E07-vps-hosting/S7.8.md)) переключены на новую базу. Восстановление из них проверено до удаления Atlas.
- [ ] Откат — возврат `DATABASE_URL` на Atlas. Atlas остаётся в режиме чтения не меньше двух недель, затем сделан финальный архив, и кластер удалён.
