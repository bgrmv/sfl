# S10.11 — Выбор дизайн-направления через design skills

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S11.8](../E11-dx-docs/S11.8.md)

**DESC:** Как администратор лиги, я хочу сравнить 2–3 дизайн-направления на реальной странице сайта, чтобы выбрать цвета и стиль до того, как их применят ко всему клиенту.

**ACs:**
- [ ] Для сравнения взяты 2–3 design skills, выбранные в [S11.8](../E11-dx-docs/S11.8.md). Каждый получает один и тот же бриф: спортивная лига, Angular Material, светлая и тёмная тема, акцентные цвета команд, читаемые таблицы.
- [ ] Каждое направление применено только к странице входа и списку матчей, в отдельной ветке или в отдельном файле темы. Остальной клиент не меняется.
- [ ] Для каждого направления сохранены скриншоты в светлой и тёмной теме, на ширине 360 и 1280 px (`docs/design/`).
- [ ] Для каждого записаны палитра (основной, акцентный, ошибка, поверхности), шрифты и проверка контраста текста по WCAG AA.
- [ ] Выбрано одно направление и записано решение: почему, что взято из других. Остальные ветки удалены.
- [ ] Выбранное направление не нарушает цвета команд из данных (`teams.color`): они читаются на любом фоне.

## Заметки

- Это выбор, а не внедрение: тема для всего клиента делается в [S10.12](S10.12.md).
