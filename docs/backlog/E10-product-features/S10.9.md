# S10.9 — Плановые задачи на сервере

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** S · **Зависит от:** [S7.6](../E07-vps-hosting/S7.6.md)

**DESC:** Как администратор лиги, я хочу, чтобы регулярная работа (например, пересчёт статистики сезона или напоминания) выполнялась сама по расписанию, чтобы не запускать её вручную.

**ACs:**
- [ ] Сценарии согласованы с владельцем продукта и перечислены в этой истории до начала работы.
- [ ] Задачи объявлены через `@nestjs/schedule` в отдельном модуле. Расписание задаётся конфигурацией, а не константой в коде.
- [ ] Задача не запускается дважды одновременно (защита от наложения долгого выполнения).
- [ ] Успех и ошибки каждого запуска пишутся в лог. Падение задачи вызывает алерт ([S9.2](../E09-observability/S9.2.md)).
