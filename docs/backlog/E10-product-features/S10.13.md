# S10.13 — Применить тему ко всем страницам

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S10.12](S10.12.md)

**DESC:** Как пользователь, я хочу, чтобы все страницы выглядели одинаково и аккуратно, чтобы сайт не казался набором несвязанных экранов.

**ACs:**
- [ ] Страницы входа, списка матчей, матча, списка игроков и игрока переведены на тему [S10.12](S10.12.md).
- [ ] В стилях компонентов не осталось жёстко заданных цветов, шрифтов и радиусов: везде токены темы. Это проверяется поиском по `src/` (hex, `rgb(`, `font-family`).
- [ ] Таблицы, карточки матчей и формы единообразны по отступам, плотности и состояниям (hover, focus, disabled, ошибка).
- [ ] Скриншоты каждой страницы в светлой и тёмной теме на ширине 360 и 1280 px приложены к PR.
- [ ] Результаты аудита доступности ([S11.11](../E11-dx-docs/S11.11.md)) учтены: нарушения высокой серьёзности исправлены.
- [ ] Поведение страниц не изменилось: клиентские тесты ([S2.5](../E02-tests-ci/S2.5.md)) проходят без правки ожиданий.

## Заметки

- Делать по одной странице на PR, чтобы ревью было по скриншотам, а не по огромному диффу.
