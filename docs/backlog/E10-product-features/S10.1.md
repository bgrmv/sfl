# S10.1 — Пагинация матчей от новых к старым

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** S · **Зависит от:** [S3.4](../E03-architecture/S3.4.md)

**DESC:** Как пользователь, я хочу видеть последние матчи первыми и подгружать старые по страницам, чтобы список открывался быстро.

**ACs:**

- [x] Матчи сортируются по дате матча по убыванию. Пагинация выполняется на сервере (`/rest/games?page=Матчи сортируются по `played_at` по убыванию.limit=`), а не на клиенте.
- [x] ~~Страница по N матчей, навигация по страницам или «показать ещё».~~ — не нужна: список клиента — один сезон (до 53 суббот), а список без сезона уже ограничен сервером ([S12.4](../E12-performance/S12.4.md)).
- [x] Выбранный сезон и страница сохраняются в URL.

## Заметки

- **Серверная часть сделана в [S12.4](../E12-performance/S12.4.md) (2026-11-17):** `GET /games?limit=&offset=`, новые первыми; клиентская навигация по страницам и параметры в URL остаются. Список сезона ограничен числом суббот, а не страницами: решить, нужна ли страница вообще, при [S10.8](S10.8.md).
- **Сделано 2026-11-17:** сезон и статус списка матчей хранятся в адресе (`?season=2025&status=Draft`, значения по умолчанию адрес не засоряют; `board-query.ts`, 3 теста); неверные значения заменяются умолчаниями.
