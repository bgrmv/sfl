# S10.1 — Пагинация матчей от новых к старым

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** S · **Зависит от:** [S3.4](../E03-architecture/S3.4.md)

**DESC:** Как пользователь, я хочу видеть последние матчи первыми и подгружать старые по страницам, чтобы список открывался быстро.

**ACs:**
- [ ] Матчи сортируются по дате матча по убыванию. Пагинация выполняется на сервере (`/rest/games?page=Матчи сортируются по `played_at` по убыванию.limit=`), а не на клиенте.
- [ ] Страница по N матчей, навигация по страницам или «показать ещё».
- [ ] Выбранный сезон и страница сохраняются в URL.
