# S10.40 — Обработка матчей: очередь с 1980 года и плавающая заметка

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** L · **Зависит от:** [S10.21](S10.21.md), [S10.35](S10.35.md), [S10.18](S10.18.md)

**DESC:** Как администратор, я хочу превращать заметки о старых матчах в заполненные матчи в удобной очереди, чтобы восстановить статистику лиги.

**ACs:**

- [ ] Пункт меню «Process games» и значок в шапке админки с числом необработанных матчей; число считается с 2011 года (с этого года ведётся статистика), годы 1980–2010 показаны архивом без статистики.
- [ ] Очередь: сводка (ждут, обработано, архив, с заметкой и без), график по годам, фильтры, строка матча с началом заметки и действием «Process» или «Mark skipped» ([S10.18](S10.18.md)).
- [ ] Шаг «Заметка»: поле для текста, скопированного вручную с sport.kornatovski, дата; подсказки системы (команды, счёт, число игроков, голов, передач, автогол, MVP, неизвестные имена); подсказки не обязательны, всё проверяет человек.
- [ ] Плавающая заметка: окно поверх любого шага и любой страницы админки, перетаскивается, сворачивается и закрывается, не пропадает при навигации (состояние в сторе и `sessionStorage`); в шапке показан «Processing: игра такого-то числа» и кнопка «Note».
- [ ] Заметка приватна: видна только администраторам, в публичный ответ не попадает ([S8.4](../E08-security-privacy/S8.4.md)).
- [ ] Из очереди можно прервать обработку и вернуться: черновик сохраняется.
- [ ] Окно доступно с клавиатуры (фокус, Esc сворачивает), не перекрывает поля формы на ширине 1280.
