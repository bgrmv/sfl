# S10.18 — Статус матча «Пропущен»

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** S · **Зависит от:** —

**DESC:** Как администратор лиги, я хочу отметить неделю, когда матч не состоялся, чтобы в ленте не было дыры и рейтинги не страдали.

**ACs:**

- [ ] В `@sfl/schemas` `EnumGameStatus` дополнен значением «Пропущен»; формы данных API общие для клиента и сервера ([ADR 0010](../../adr/0010-zod-mini-in-shared-schemas.md)).
- [ ] Матч со статусом «Пропущен» не требует составов и статистики, не учитывается ни в одном рейтинге и расчёте метаданных; правило записано в [GLOSSARY.md](../../../GLOSSARY.md) (сделано).
- [ ] Расчёт статистики пропускает такие матчи; тест на это и на `it.fails`-кейсы расчёта не ломается.
- [ ] Клиент: администратор создаёт «Пропущен» в форме матча, в ленте неделя отмечена («Skipped»), блок «Ближайший матч» не ломается.
- [ ] `pnpm check` проходит.

## Заметки

- Источник: решение владельца 2026-11-13: матч состоится в любую погоду, с 1980 года ни одна неделя не пропущена; статус введён на всякий случай.
