# S10.41 — Теги на фотографиях и фильтр по игрокам

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S10.23](S10.23.md)

**DESC:** Как болельщик, я хочу фильтровать фотоальбом по игрокам, чтобы найти фото с теми, кого хочу увидеть.

**ACs:**

- [ ] У фотографии есть теги: игроки (ссылка на карточку), матч, при желании свободные теги; администратор расставляет теги при загрузке и потом.
- [ ] Быстрый поиск по тегам в одной строке: набор текста даёт подсказки по группам «Players», «Games», «Seasons», «Tags» (свободные теги с `#`), стрелки и Enter, Backspace убирает последний тег; выбранные теги видны чипами с крестиком; ответ приходит быстрее 200 мс на ~500 файлах (индекс по тегам).
- [ ] Быстрые теги над сеткой: популярные игроки, сезоны (S26, S25…), события (`#team-photo`, `#goal`, `#rain`) с числом файлов; режим «All of them» (все выбранные) и «Any of them» (любой); над результатом число найденных, «Also often on them» (сопутствующие теги) и «Copy link to this search» (фильтр в адресе).
- [ ] Просмотр: большое фото или видео, переход вперёд и назад, лента миниатюр, отметки игроков на кадре, список «In this photo», теги с крестиками для админа, «Copy link», «Download», комментарии.
- [ ] В альбоме выбор игроков: можно отметить нескольких, показываются фото, где есть все отмеченные (режим «все» и «любой из»).
- [ ] Из карточки игрока ссылка «Фото с игроком»; из матча ссылка «Фото матча».
- [ ] Игрок может запросить снятие тега со своего фото; решение за админом ([S8.4](../E08-security-privacy/S8.4.md)).
- [ ] Макеты: галерея, фильтр по тегам, просмотр, телефон ([секция «3н»](../../design/feature-review.md)).
