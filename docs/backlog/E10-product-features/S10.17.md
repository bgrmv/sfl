# S10.17 — Личный кабинет игрока

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** L · **Зависит от:** [S10.12](S10.12.md), [S8.1](../E08-security-privacy/S8.1.md)

**DESC:** Как игрок, я хочу войти и увидеть свою статистику и графики за сезон и за карьеру, чтобы следить за собой и за местом в рейтинге.

**ACs:**

- [ ] Учётная запись связана с игроком по id игрока (решение владельца 2026-11-13); связь записана в [GLOSSARY.md](../../../GLOSSARY.md); позже привязку заменит вход через Google ([S8.13](../E08-security-privacy/S8.13.md)); учтена защита персональных данных ([S8.4](../E08-security-privacy/S8.4.md)).
- [ ] После входа игрок видит «Мой кабинет»: главный показатель, график по матчам, таблица по сезонам, переключатель «сезон / карьера».
- [ ] Игрок меняет в кабинете только своё допустимое (например, аватар, никнейм), права проверяются на сервере ([docs/PROJECT.md](../../PROJECT.md), раздел 5.1) и покрыты строкой в `test/api/access.test.ts`.
- [ ] Администратор по-прежнему видит и правит всех игроков.
- [ ] Каркас страницы общий с страницей игрока и капитана ([S10.4](S10.4.md), [S10.6](S10.6.md)): один компонент графика, одна раскладка.

## Заметки

- Источник: ответ владельца 2026-11-13 в [дизайн-брифе](../../design/brief.md), раздел 5: упор на статистику, графики, личный кабинет, капитанов и команды.
