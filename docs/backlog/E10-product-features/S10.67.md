# S10.67 — Мастер матча и подтверждения на данных

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** L · **Зависит от:** [S10.54](S10.54.md), [S10.35](S10.35.md), [S10.27](S10.27.md)

**DESC:** Как владелец лиги, я хочу, чтобы блоки дизайна «Табло», которые сейчас показывают выдуманные данные, читали настоящие, чтобы страницы были правдой, а не макетом.

Основание: блоки сделаны в [теме «Табло»](../../design/theme.md) с флагами `dummy: true` в `client/src/shared/config/feature-flags.ts`.

Флаги блоков: `admin.wizard`, `admin.confirm`.

**ACs:**

- [x] Шесть шагов мастера сохраняют матч черновиком на сервере (аренда [S10.54](S10.54.md)).
- [x] Публикация по двум подтверждениям разных администраторов; отзыв с причиной и пересчётом рейтингов.
- [ ] Рабочая форма `/games/create` заменяется мастером или встраивается в него.
- [x] Для каждого блока истории флаг переведён в `dummy: false`, импорт из `@shared/dummy` и комментарий `DUMMY (...)` убраны.
- [x] Новое поведение покрыто тестами (сначала тест, потом домен, потом клиент: [ADR 0013](../../adr/0013-tests-first-then-domain-then-local.md)); `pnpm check` проходит.

## Заметки

- Создано 2026-11-16 при подключении блоков дизайна к данным: то, что можно было подключить без новой серверной части, уже подключено (главная, игры, игрок, игроки, капитаны, календарь, сезоны, сравнение, профиль).
- **Сделано 2026-11-17:** мастер `/admin/wizard` (и `/admin/wizard/:season/:number` для правки) работает на `NewGameStore` и `GameLease`: игра, капитаны, драфт, статистика, порядок голов, итог с проверками; черновик сохраняется на сервере (`POST`/`PATCH`, после создания остаётся в мастере). Порядок голов (`goal-order.ts`: `applyEvents`, `scoreAfter`, `renumber`) задаёт голы и передачи игроков, поэтому итоги не расходятся с порядком; ошибки порядка — `gameEventViolations` из `@sfl/schemas`, `aria-live`. Подтверждения и отзыв — на `/admin/confirm` ([S10.35](S10.35.md)); флаги `admin.wizard` и `admin.confirm` — `live`.
- **Осталось:** (1) AC «`/games/create` заменяется мастером» не отмечен: классическая форма остаётся и открывается ссылкой из мастера, пока владелец не посмотрит мастер в браузере; (2) ~~оценка шансов в итоге мастера~~ — сделано (см. ниже); (3) живая подача голов (режим «Live scorer») и «Skip, order unknown» как отдельные режимы; (4) автосохранение мастера как в форме ([S10.54](S10.54.md)); (5) участники автогола не вводятся (открытый вопрос S10.27); (6) сверка с досками «Табло» в браузере.
- **Оценка шансов (2026-11-17):** в итоге мастера показаны «Estimate before the game» с подписью «estimate» и подсказкой «not a bet»; считает `winChance` из `@sfl/domain` (в клиент добавлена зависимость `workspace:*`, как `@sfl/schemas`) по очкам выбранной системы счёта и сезону матча; вход игрока — `strengthInput`, среднее по лиге — `leagueAverage` (`entities/player/lib/win-chance-input.ts`, 4 теста). «Последний матч» берётся из `lastResult` системы счёта. Показ «было ожидаемо» после публикации — в афише ([S10.77](S10.77.md)).
