# S10.45 — Сравнение систем счёта и выбор системы в шапке

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S10.38](S10.38.md), [S10.30](S10.30.md), [S10.33](S10.33.md)

**DESC:** Как посетитель, я хочу видеть две системы счёта рядом, как таблицу сравнения, и выбирать систему в шапке, чтобы не листать табы и сразу видеть рейтинг в нужной системе.

**ACs:**

- [ ] Страница сравнения: слева перечень показателей, справа две колонки «Ancient» и «Positional» с карточками систем и кнопкой «Use this system»; строки сгруппированы («Points of the player», «Result of the game», «Numbers and ranking»).
- [ ] У каждой строки метка «Same» или «Different»; отличающиеся значения выделены; переключатель «Show only differences» оставляет только различия.
- [ ] Блок «Result of the game» показывает по каждой позиции значение в старой системе («0, result not counted») и в новой («+4 / −4», «+3 / −3», «+2 / −2», «+1 / −1», крайний «+? / −?» до решения), ничья 0, трансфер без результата.
- [ ] «Try it»: выбор позиции и результата, один и тот же набор действий считается в обеих системах и показывает итог рядом.
- [ ] Значения берутся из тех же констант, что и расчёт на сервере; тест на совпадение с таблицей ([S10.38](S10.38.md)).
- [ ] Выбор системы в шапке (меню «Scoring: Ancient ▾» с описанием двух систем, ссылками «Compare the systems» и «How points work») на страницах с рейтингом: главная, игроки, игрок, сезоны, очки; выбор запоминается в профиле, для гостя на устройстве, значение по умолчанию задаёт владелец.
- [ ] Таблицы переключения (табы «Ancient/Positional») на этих страницах заменены строкой «Scoring: …, set in the header»; адрес страницы содержит `?system=positional`, чтобы ссылкой можно было делиться.
- [ ] Меню доступно с клавиатуры (`listbox`), на 360 px помещается в шапку; тёмная и светлая темы.

## Заметки

- Решение владельца 2026-11-15: по умолчанию выбрана старая система («Default for now»), пока все к ней привыкли; владелец может сменить умолчание.
- Макет: холст «Табло», секция «3к».
- В примере владельца защитник получает +4 за победу; в [GLOSSARY.md](../../../GLOSSARY.md) записано ±3 для защитника и ±4 для вратаря. В макете значения из глоссария; уточнить.
