# S10.73 — Сверка клиента с досками «Табло»

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S10.12](S10.12.md)

**DESC:** Как владелец лиги, я хочу, чтобы страницы клиента совпадали с досками холста «Табло» по композиции, размерам и отступам, чтобы сайт выглядел как утверждённый дизайн, а не как его пересказ.

Таблица «доска → страница → статус»: [theme.md](../../design/theme.md), раздел «Сверка с досками».

**ACs:**

- [x] Шкала типографики, ширины страниц, отступы и сетки досок записаны токенами и классами kit (`tokens.scss`, `kit.scss`); страницы берут значения только оттуда.
- [x] h3 — Inter 700 без капса; страницы игрока и матча собраны из секций (`sfl-section`) с карточками h3 внутри, как на досках.
- [x] Система счёта выбирается в шапке и действует на всех страницах с рейтингом (`RatingSystemStore`, тест); локальные переключатели убраны.
- [x] Подвал по доске `Footer`: соцсети, язык, переключатель темы (активна только тёмная до [S10.50](S10.50.md)); вход по доске `SignIn`.
- [x] Админка по доскам `Dashboard` и `AdminPlayers`: сайдбар со счётчиками, без публичной шапки.
- [x] «Субботы сезона» на странице игрока — сетка 13 колонок из настоящих данных (тест).
- [ ] Каждая страница сверена с доской глазами в браузере на 1280 и 360 px; расхождения исправлены или записаны в таблицу сверки.
- [ ] Страницы «только общие размеры» из таблицы сверки сведены с досками поблочно (вместе с историями [S10.56](S10.56.md)–[S10.72](S10.72.md)).
- [ ] Щиты команд на табло матча и вид «Table» чисел игрока сделаны по доскам `Game` и `PlayerTable`.
- [ ] `pnpm check` проходит.

## Заметки

- Создано 2026-11-16. Сверка сделана по разметке досок (размеры, отступы, порядок блоков): в контейнере нет браузера, а доски не рендерятся локально (нет `support.js`). Проверка глазами осталась открытым AC.
- Отступление от доски: список игр сделан таблицей, а не строками, потому что владелец попросил сортировку и фильтры.
