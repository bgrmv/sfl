# S10.50 — Светлая тема (делается последней)

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S10.13](S10.13.md), [S10.49](S10.49.md)

**DESC:** Как посетитель, я хочу при желании включить светлую тему, чтобы читать сайт днём; владелец решил делать её в самом конце.

**ACs:**

- [ ] Второй набор токенов `--sfl-*` для светлой темы (бежево-чёрная палитра «Табло», см. [brief.md](../../design/brief.md)); компоненты не меняются, потому что берут значения из токенов.
- [ ] Переключатель темы в шапке и футере (Light, Dark, Auto), пока этой истории нет, он скрыт и сайт всегда тёмный; выбор запоминается ([S10.42](S10.42.md), [S10.33](S10.33.md)); без вспышки неверной темы.
- [ ] Контраст 4,5:1 по всем парам «текст на фоне», проверка тестом токенов; цвета команд и графиков читаемы в обеих темах.
- [ ] Светлые доски холста «Табло» служат справочными; недостающие нарисовать по тёмным.
- [ ] Скриншоты ключевых страниц в светлой теме на 360 и 1280 px приложены к PR.

## Заметки

- Решение владельца 2026-11-15: основная тема тёмная; светлая только в конце, приоритет самый низкий. До этого `color-scheme: dark` задан в `index.html`, новые страницы и компоненты проверяются только в тёмной теме, но стили пишутся на токенах, чтобы вторая тема была дешёвой.
- Не блокирует ни одну другую историю.
