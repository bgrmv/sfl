# S10.34 — Сезоны и зал славы

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S10.12](S10.12.md), [S10.24](S10.24.md)

**DESC:** Как болельщик, я хочу видеть итоги сезона, награды и рекорды лиги, чтобы понимать, кто чего добился.

**ACs:**

- [ ] Переключатель сезонов S26 (по умолчанию), S25…S11 и «All time» ([S10.30](S10.30.md)); сводка: сыграно суббот, голы, голы за игру, число игроков.
- [ ] MVP считается автоматически для каждой позиции и не снимается; администратор может вручную добавить ещё один MVP другому игроку на той же позиции (запись в журнал, [GLOSSARY.md](../../../GLOSSARY.md)).
- [ ] Награда «лучший защитник» считается по плюс-минусу ([GLOSSARY.md](../../../GLOSSARY.md)).
- [ ] Награда «лучший вратарь» без умолчания: показатель вратаря (например, число отбитых ударов) вносится вручную в статистику матча; без него награда не присуждается.
- [ ] Первая тройка по очкам; награды сезона (MVP, лучший бомбардир, лучший по передачам, лучший капитан, защитник, вратарь) считаются из данных; формулы описаны в [GLOSSARY.md](../../../GLOSSARY.md).
- [ ] «BMW против HONDA»: победы и голы по цвету формы; сравнение сезонов.
- [ ] Зал славы: рекорды за все сезоны (очки за сезон, голы за игру, серия побед, крупнейшая победа); ранние годы вносит владелец ([S10.24](S10.24.md)).
- [ ] Незавершённый сезон помечен «в процессе»; пустой сезон показывает состояние по [S10.14](S10.14.md).
- [ ] Ширина 360 px, тёмная и светлая темы.

## Заметки

- Макет: холст «Табло», секция «4в».
- Решение владельца 2026-11-15: защитник по ±, у вратаря умолчания нет, MVP автоматический и не снимается, вручную можно добавить дополнительный на ту же позицию. Остаётся уточнить меру MVP для нападающего, крайнего и полузащитника (голы с весом и передачи, как сейчас?).
- Поле вратаря в статистике матча: [S10.27](S10.27.md) не затрагивает, нужна отдельная правка схемы матча.
