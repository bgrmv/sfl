# S10.2 — Удалённые матчи не отображаются

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** S · **Зависит от:** —

**DESC:** Как пользователь, я хочу, чтобы удалённые матчи не появлялись в списках и статистике, чтобы видеть только реальные игры.

**ACs:**

- [x] Удаление мягкое (`deleted_at`). Удалённый матч не попадает в списки, графики и расчёт статистики.
- [x] Администратор может восстановить матч.
- [x] После удаления или восстановления статистика пересчитывается.

## Заметки

- **Сделано 2026-11-17:** `DELETE /games/:id` скрывает матч: `deletedAt`, статус «Черновик», подтверждения и аренда сняты, вклад в статистику вычтен (как раньше при удалении); матч не попадает в списки, `GET /games/:id` отвечает 404 (и для несуществующего матча, раньше был 200 с `null`), подтвердить, взять в аренду или править его нельзя. Админ видит удалённые `GET /games/deleted` и возвращает `POST /games/:id/restore`: матч возвращается черновиком, в статистику попадает после двух подтверждений ([S10.35](S10.35.md)); если номер уже занят новым матчем, восстановление отвечает 409. Уникальный индекс теперь `{number, season, deletedAt}`; на проде старый индекс удаляется вручную ([runbook](../../runbooks/mongo-indexes.md)). Тесты `games.softdelete.test.ts` (7), строки матрицы доступа. Клиентского списка удалённых нет: добавить в админку при необходимости.
