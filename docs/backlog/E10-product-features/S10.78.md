# S10.78 — OpenGraph: превью ссылок на сайт в мессенджерах и соцсетях

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S10.77](S10.77.md), [S8.10](../E08-security-privacy/S8.10.md)

**DESC:** Как игрок, я хочу, чтобы ссылка на матч, игрока или главную страницу, отправленная в чат или соцсеть, показывала красивую карточку (заголовок, описание, картинка), чтобы друзья сразу видели, о чём ссылка, и хотели её открыть.

Основание: решение владельца 2026-11-17. [ADR 0001](../../adr/0001-monolith-nest-angular-ssr-on-vps.md) отложил SSR и сказал, что превью закрываются memmo и PWA; Open Graph-тегов в проекте нет. Боты мессенджеров не выполняют JavaScript, поэтому теги надо отдавать в самом HTML.

**ACs:**

- [ ] Способ записан в новом ADR: теги подставляет Nest в `index.html` для публичных маршрутов (главная, матч, игрок, капитаны, список игр) без полного SSR; полный SSR ([S7.5](../E07-vps-hosting/S7.5.md)) остаётся опцией. Причины и отвергнутые варианты (prerender, SSR, memmo) — в ADR.
- [ ] Для каждого публичного маршрута отдаются `<title>`, `description`, `og:title`, `og:description`, `og:type`, `og:url`, `og:image` (с `og:image:width`, `height` и `alt`), `og:locale`, `twitter:card=summary_large_image`. Для остальных маршрутов — теги по умолчанию.
- [ ] Адреса абсолютные и берутся из настройки `PUBLIC_URL` (в `.env.example` и конфиге с проверкой). Домена у сайта пока нет (открытый вопрос 5): локально проверяется на `https://sfl.com:3001`, в проде значение появится вместе с [S7.3](../E07-vps-hosting/S7.3.md).
- [ ] Картинка 1200×630 генерируется сервером для каждого вида страницы: главная (афиша боя из [S10.77](S10.77.md), когда капитаны известны), матч (счёт, команды, дата), игрок (имя, номер, ключевые числа), по умолчанию (название лиги). Шрифты Inter и Oswald с латиницей, `latin-ext` и кириллицей. Библиотека и причина выбора записаны в ADR (зависимость добавляется только с причиной).
- [ ] Ответы с картинкой кешируются (`Cache-Control`, `ETag`), на маршрут действует лимит запросов ([S8.11](../E08-security-privacy/S8.11.md)): генерация нагружает процессор. Неизвестный id отдаёт 404 по [S8.5](../E08-security-privacy/S8.5.md), а не картинку с пустыми полями.
- [ ] Безопасность и данные: значения в тегах экранируются (тест на `"><script>` в имени игрока); в тегах и на картинке только публичные поля, без email и персональных данных ([S8.10](../E08-security-privacy/S8.10.md), [S8.4](../E08-security-privacy/S8.4.md)).
- [ ] Новые маршруты помечены `@Public()` и добавлены в матрицу `test/api/access.test.ts`; тесты API: теги в HTML для матча, игрока и неизвестного пути, `image/png` размером 1200×630, экранирование. Сначала тест, потом код ([ADR 0013](../../adr/0013-tests-first-then-domain-then-local.md)).
- [ ] Клиент ставит `<title>` при смене маршрута (сервис `Title`), чтобы вкладка и история браузера были осмысленными.
- [ ] Проверка: `curl` с User-Agent бота показывает теги и картинку локально; проверка в Telegram, WhatsApp и отладчике Facebook выполняется после деплоя ([S7.6](../E07-vps-hosting/S7.6.md)), результат записывается в заметки. `pnpm check` проходит.

## Заметки

- Создано 2026-11-17 по просьбе владельца.
- Картинка афиши и картинка превью — один рисунок ([S10.77](S10.77.md)), чтобы сайт и ссылка не расходились.
- Локальная часть делается сразу, проверка в мессенджерах ждёт домен и деплой (P4).
