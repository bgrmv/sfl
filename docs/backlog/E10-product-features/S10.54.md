# S10.54 — Один матч редактирует один администратор и сохранение черновика

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** L · **Зависит от:** [S3.23](../E03-architecture/S3.23.md), [S10.21](S10.21.md)

**DESC:** Как администратор лиги, я хочу, чтобы матч, который я заполняю, не мог одновременно редактировать другой администратор, и чтобы черновик сохранялся в фоне, чтобы не потерять работу и не затереть чужую.

Решение о механизме: [ADR 0015](../../adr/0015-exclusive-match-editing-lease-in-db.md) (аренда в базе, версия документа, WebSocket только для уведомлений).

**ACs:**

- [x] Тесты первыми: два администратора берут один матч, второй получает `409` с именем владельца; аренда истекает без пульса; сохранение без аренды или со старой версией отклоняется; правка очищает подтверждения.
- [x] Схема матча в `@sfl/schemas`: поля `lock` и `version`; маршруты `POST /games/:id/lock` (взять и продлить), `DELETE /games/:id/lock`; строки в `test/api/access.test.ts`.
- [x] Аренда берётся одной атомарной операцией; пульс каждые 30 секунд продлевает её на 2 минуты; закрытие матча отпускает.
- [x] Клиент: при занятом матче показывает, кто его редактирует и до какого времени, форма доступна только для чтения; уведомление, когда матч освободился (опрос, позже WebSocket [S10.10](S10.10.md)).
- [x] Автосохранение черновика в фоне (debounce), подпись «Все изменения сохранены» и короткое уведомление; невалидный черновик сохраняется как «Черновик», публикация остаётся явным действием.
- [x] Статус «Опубликован» нельзя выставить напрямую: только домен после двух и более подтверждений от разных людей ([S10.35](S10.35.md)); любая правка черновика очищает подтверждения. Правило записано в [GLOSSARY.md](../../../GLOSSARY.md).
- [x] Заполнивший матч может быть одним из двух подтверждающих, но публикация требует минимум одного подтверждающего, который его не заполнял (решение владельца 2026-11-16); срок аренды и частота пульса подтверждены.
- [x] `pnpm check` зелёный.

## Заметки

- Идея: владелец, 2026-11-16 («матч можно формировать, один и тот же матч не должны брать два администратора; в базе или WebSocket»). Выбрана база: состояние переживает перезапуск и переподключение, WebSocket не обязателен.
- **Сделано 2026-11-17:** сервер: поля `version` и `lock` у матча, `POST /games/:id/lock` (взять и продлить, одна атомарная операция), `DELETE /games/:id/lock`; `PUT` и `PATCH` принимает только держатель аренды (иначе 409), версию из заголовка `If-Match` (старая версия: 412), правка поднимает `version` и очищает подтверждения; опубликованный матч не берётся (409, сначала отзыв, [S10.35](S10.35.md)); аренду видят админ и модератор, публика нет. Срок 2 минуты и пульс 30 секунд приняты по предложению ADR 0015 (владелец их не менял). Тесты `games.lock.test.ts` (9), строки матрицы доступа. Клиент: `GameLease` (взять, пульс, `busy` с именем и временем, освобождённый матч берётся сам, отпускание при закрытии), баннер и закрытая форма в `game-form-page`, `If-Match` при сохранении.
- **Автосохранение (2026-11-17):** `canAutosave` и `autosaveLabel` (`features/game-edit/model/autosave.ts`, тесты): существующий матч, аренда у нас, без ошибок форму и правил, есть что сохранять; пауза 4 секунды после последней правки; подпись «All changes saved» / «Saved on its own in a few seconds» / «Fix the errors to save the changes». Невалидный черновик не сохраняется: сервер не принимает матч без капитана (правила матча); публикация никогда не побочный эффект. Уведомление «матч освободился» сделано как автоматическое открытие формы без всплывающего сообщения.
