# S10.12 — Тема Angular Material: палитра, типографика, тёмная тема

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S10.11](S10.11.md), [S1.4](../E01-dependency-upgrades/S1.4.md)

**DESC:** Как разработчик, я хочу единую тему Angular Material с палитрой и типографикой из выбранного направления, чтобы цвета и стили задавались в одном месте, а не в каждом компоненте.

**ACs:**

- [x] Тема подключена в глобальных стилях клиента через API темизации Angular Material актуальной версии. Палитра и типографика берутся из решения [S10.11](S10.11.md).
- [x] Основная тема тёмная (`color-scheme: dark`); светлая делается в конце отдельной историей [S10.50](S10.50.md), но токены сразу пишутся так, чтобы набор значений можно было подменить.
- [x] Цвета, радиусы, отступы и шрифты вынесены в токены (CSS-переменные или переменные темы). Новые компоненты берут значения только оттуда.
- [x] Контраст текста и интерактивных элементов в тёмной теме соответствует WCAG AA (светлая: [S10.50](S10.50.md)).
- [x] Цвета команд (`teams.color`) читаемы в тёмной теме.
- [x] `ng build --configuration production` проходит без новых предупреждений, размер основного бандла вырос не больше чем на 5 %.
- [x] Описание темы (токены, как добавить цвет, как проверить контраст) лежит в `docs/design/theme.md`.

## Заметки

- Зависимость от [S1.4](../E01-dependency-upgrades/S1.4.md) сознательна: в Angular Material 18.2 поддержка Material 3 экспериментальная, и после обновления пришлось бы переделывать тему. Если обновление Angular сильно отстаёт, начать можно на 18.2 на токенах и CSS-переменных, а подключение API темы M3 оставить на после S1.4.
- 2026-11-16: тема сделана вместе с UI-kit «Табло» ([theme.md](../../design/theme.md)). Не отмечены: контраст (нет теста пар «текст на фоне»), цвета команд из `teams.color`, проверка предупреждений сборки и размера бандла против базовой линии. Статус остаётся ❌.
- **Закрыта 2026-11-17:** контраст темы проверяет `client/scripts/contrast.test.mjs` (шаг `client:contrast` в `pnpm check`, `node --test`; 18 пар «текст на фоне» читаются из `tokens.scss`, минимум 4,5:1), в том числе цвета команд (`honda`, `bmw`): `teams.color` принимает только `WHITE` и `RED`. Предупреждения сборки: новых нет (остались старые про Sass `@import`); initial 731 КБ в начале дня, 642 КБ сейчас. Тест вне `ng test` сознательно: опция `loader` для `.scss` ломала разрешение `zod/mini` у остальных тестов клиента.
