# S10.12 — Тема Angular Material: палитра, типографика, тёмная тема

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S10.11](S10.11.md), [S1.4](../E01-dependency-upgrades/S1.4.md)

**DESC:** Как разработчик, я хочу единую тему Angular Material с палитрой и типографикой из выбранного направления, чтобы цвета и стили задавались в одном месте, а не в каждом компоненте.

**ACs:**
- [ ] Тема подключена в глобальных стилях клиента через API темизации Angular Material актуальной версии. Палитра и типографика берутся из решения [S10.11](S10.11.md).
- [ ] Есть светлая и тёмная тема. Переключатель уважает системную настройку (`prefers-color-scheme`) и запоминает выбор пользователя.
- [ ] Цвета, радиусы, отступы и шрифты вынесены в токены (CSS-переменные или переменные темы). Новые компоненты берут значения только оттуда.
- [ ] Контраст текста и интерактивных элементов в обеих темах соответствует WCAG AA.
- [ ] Цвета команд (`teams.color`) остаются читаемыми в обеих темах.
- [ ] `ng build --configuration production` проходит без новых предупреждений, размер основного бандла вырос не больше чем на 5 %.
- [ ] Описание темы (токены, как добавить цвет, как проверить контраст) лежит в `docs/design/theme.md`.

## Заметки

- Зависимость от [S1.4](../E01-dependency-upgrades/S1.4.md) сознательна: в Angular Material 18.2 поддержка Material 3 экспериментальная, и после обновления пришлось бы переделывать тему. Если обновление Angular сильно отстаёт, начать можно на 18.2 на токенах и CSS-переменных, а подключение API темы M3 оставить на после S1.4.
