# S10.10 — Обновления в реальном времени

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S7.3](../E07-vps-hosting/S7.3.md), [S7.5](../E07-vps-hosting/S7.5.md)

**DESC:** Как болельщик, я хочу видеть счёт и события матча без обновления страницы, чтобы следить за игрой, пока она идёт.

**ACs:**
- [ ] Сценарии согласованы с владельцем продукта и перечислены в этой истории до начала работы.
- [ ] Gateway на `@nestjs/websockets` в том же процессе Nest. Публичные события только читаются, изменения — по-прежнему через `/rest` с авторизацией.
- [ ] Клиент подключается только в браузере (не при SSR) и переподключается после обрыва.
- [ ] Соединения проходят через Caddy ([S7.3](../E07-vps-hosting/S7.3.md)) по `wss://`.
