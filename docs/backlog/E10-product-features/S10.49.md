# S10.49 — Ввод матчей 2011–2026 назначенными модераторами

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** L · **Зависит от:** [S10.35](S10.35.md), [S10.40](S10.40.md), [S10.46](S10.46.md)

**DESC:** Как владелец лиги, я хочу, чтобы несколько назначенных модераторов вручную внесли матчи 2011–2026 по старым заметкам и подтверждали работу друг друга, чтобы статистика была полной и проверенной.

**ACs:**

- [ ] Владелец назначает модераторов (роль `MODERATOR`, [S10.35](S10.35.md)); каждому выдаётся доступ ([S10.48](S10.48.md)); число и состав определяются владельцем.
- [ ] Регламент ввода в `docs/runbooks/match-entry.md`: как читать заметку, порядок шагов мастера, что делать с неизвестными именами, спорными счётами и пропущенными неделями ([S10.18](S10.18.md)), как отмечать сомнения.
- [ ] Каждый матч подтверждают двое разных модераторов ([S10.35](S10.35.md)); один заполняет, другой проверяет по заметке.
- [ ] Прогресс виден в очереди ([S10.40](S10.40.md)): сколько ждёт, сколько внесено, сколько подтверждено, кто взял в работу; один матч не берут двое одновременно.
- [ ] Контрольные проверки: счёт равен сумме голов, у каждого гола автор, число игроков в командах разумно; расхождение блокирует публикацию или помечается.
- [ ] Порядок: сначала свежие сезоны (S26 назад к S11), в черновиках; публикация только после подтверждений; итоги сезона пересчитываются при каждой публикации.
- [ ] Журнал: кто внёс, кто подтвердил, когда; отзывы с причиной.

## Заметки

- Решение владельца 2026-11-15: вводят несколько модераторов вручную, будут назначены; админка первой, чтобы наполнять контент.
- Темп и сроки определяет число модераторов; оценка в [implementation-assessment.md](../../design/implementation-assessment.md).
