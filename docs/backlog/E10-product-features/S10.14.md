# S10.14 — Состояния интерфейса и движение

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S3.10](../E03-architecture/S3.10.md)

**DESC:** Как администратор лиги, я хочу, чтобы интерфейс всегда говорил, что происходит: идёт загрузка, список пуст, действие выполнено или не удалось, чтобы не гадать, сработала ли кнопка.

**ACs:**

- [ ] Общий сервис уведомлений (Material snackbar) показывает результат сохранения, удаления, публикации и ошибки сети; названия действий едины (кнопка «Опубликовать», уведомление «Опубликовано»); таймаут разумный (не 20 секунд), `polite` для успеха и `assertive` только для ошибок.
- [ ] Во всех списках и таблицах есть `@empty` с понятным текстом и действием («Добавьте первого игрока»).
- [ ] Загрузка оформлена одним подходом (скелетон для списков и карточек, полоса для действий); искусственная задержка `@loading (minimum 1.5s)` убрана.
- [ ] Форма входа показывает понятную ошибку при неверном пароле и при недоступном сервере.
- [ ] Движение отвечает на действия (диалоги, добавление и удаление строк) через CSS `animate.enter/leave`; учитывается `prefers-reduced-motion`; бесконечная анимация градиента в карточке матча убрана или отключается этим media-запросом.
- [ ] В стилях есть брейкпоинты, таблицы читаются на 360 px (проверка скриншотами на 360 и 1280 px).
- [ ] Удалены закомментированные заготовки `LIKE`/`SHARE` в `game-card.component.html`.
- [ ] Язык интерфейса сейчас английский (решение владельца 2026-11-13, позже мультиязычность — [S10.15](S10.15.md)). Тексты приведены к единому английскому словарю действий и состояний, `lang="en"`, строки не склеиваются из кусков (чтобы их потом можно было вынести в переводы).
