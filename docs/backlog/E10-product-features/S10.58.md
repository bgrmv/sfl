# S10.58 — Страница игрока: радар, суббота-календарь, позиции и цвета команд, соперники и союзники

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** L · **Зависит от:** [S10.29](S10.29.md), [S10.4](S10.4.md)

**DESC:** Как владелец лиги, я хочу, чтобы блоки дизайна «Табло», которые сейчас показывают выдуманные данные, читали настоящие, чтобы страницы были правдой, а не макетом.

Основание: блоки сделаны в [теме «Табло»](../../design/theme.md) с флагами `dummy: true` в `client/src/shared/config/feature-flags.ts`.

Флаги блоков: `player.radar`, `player.rivals`.

**ACs:**

- [ ] Радар «стиль игры»: шесть осей против среднего по лиге, значения считает домен.
- [ ] Календарь суббот сезона: сыграл, пропустил, очки; берутся из `byGame` и расписания.
- [ ] Доля позиций и процент побед за BMW и HONDA из статистики игр.
- [ ] «Тяжёлые соперники» и «лучшие союзники» (порог 5 игр) по истории составов.
- [ ] Блоки больше не используют `@shared/dummy`, флаги `dummy: false`.
- [ ] Для каждого блока истории флаг переведён в `dummy: false`, импорт из `@shared/dummy` и комментарий `DUMMY (...)` убраны.
- [ ] Новое поведение покрыто тестами (сначала тест, потом домен, потом клиент: [ADR 0013](../../adr/0013-tests-first-then-domain-then-local.md)); `pnpm check` проходит.
