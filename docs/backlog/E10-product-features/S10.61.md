# S10.61 — Страница матча: порядок голов и карта расстановки

**Эпик:** 10 — Продуктовые фичи · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P3 · **Размер:** M · **Зависит от:** [S10.27](S10.27.md), [S10.38](S10.38.md)

**DESC:** Как владелец лиги, я хочу, чтобы блоки дизайна «Табло», которые сейчас показывают выдуманные данные, читали настоящие, чтобы страницы были правдой, а не макетом.

Основание: блоки сделаны в [теме «Табло»](../../design/theme.md) с флагами `dummy: true` в `client/src/shared/config/feature-flags.ts`.

Флаги блоков: `game.events`, `game.map`.

**ACs:**

- [ ] Порядок голов (счёт до и после, автор, передачи) выводится из сохранённой последовательности.
- [ ] Карта расстановки рисует позиции игроков из сохранённых координат.
- [ ] Если порядок не внесён, блок скрывается, а не показывает пустую таблицу.
- [ ] Для каждого блока истории флаг переведён в `dummy: false`, импорт из `@shared/dummy` и комментарий `DUMMY (...)` убраны.
- [ ] Новое поведение покрыто тестами (сначала тест, потом домен, потом клиент: [ADR 0013](../../adr/0013-tests-first-then-domain-then-local.md)); `pnpm check` проходит.

## Заметки

- Создано 2026-11-16 при подключении блоков дизайна к данным: то, что можно было подключить без новой серверной части, уже подключено (главная, игры, игрок, игроки, капитаны, календарь, сезоны, сравнение, профиль).
