# S5.4 — RLS-политики и роли

**Эпик:** 5 — Бэкенд на Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S5.3](../E05-supabase-backend/S5.3.md)

**DESC:** Как администратор лиги, я хочу, чтобы права доступа проверялись в самой базе, чтобы их нельзя было обойти прямым запросом.

**ACs:**
- [ ] RLS включён на всех таблицах `public`.
- [ ] Чтение опубликованных матчей, игроков, команд и статистики доступно всем, включая анонимов.
- [ ] Черновики матчей видят только `ADMIN` и `MODERATOR`.
- [ ] Запись — только `ADMIN` и `MODERATOR`. Управление ролями — только `ADMIN`.
- [ ] Чувствительные поля профиля (email, возраст) не видны анонимам.
- [ ] Тесты политик (pgTAP или интеграционные через supabase-js) проходят в CI для каждой роли.
