# S5.3 — Аутентификация через Supabase Auth

**Эпик:** 5 — Бэкенд на Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** M · **Зависит от:** [S4.3](../E04-migration-design/S4.3.md), [S5.2](../E05-supabase-backend/S5.2.md)

**DESC:** Как пользователь, я хочу входить через Supabase Auth, чтобы не зависеть от самописной логики токенов.

**ACs:**
- [ ] Вход по email и паролю через `supabase-js` на клиенте. Самописные access/refresh-токены удалены.
- [ ] При создании пользователя триггер создаёт `profiles`.
- [ ] Роль пользователя доступна в JWT (custom claim) для RLS.
- [ ] Реализована выбранная в [S4.3](../E04-migration-design/S4.3.md) стратегия миграции паролей.
- [ ] Регистрация через публичную форму выключена, если она не нужна лиге.
