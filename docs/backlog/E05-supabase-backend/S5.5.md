# S5.5 — Расчёт статистики в Supabase

**Эпик:** 5 — Бэкенд на Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** L · **Зависит от:** [S3.1](../E03-architecture/S3.1.md), [S5.2](../E05-supabase-backend/S5.2.md)

**DESC:** Как пользователь, я хочу, чтобы статистика игроков обновлялась сразу после публикации матча, чтобы видеть актуальные цифры без ручного пересчёта.

**ACs:**
- [ ] Расчёт выполняется доменным модулем из [S3.1](../E03-architecture/S3.1.md) в Edge Function или переписан на SQL. Выбор записан в ADR.
- [ ] Пересчёт запускается при публикации, изменении и удалении матча и выполняется в транзакции.
- [ ] Есть ручной полный пересчёт сезона для администратора.
- [ ] Golden-master тест ([S2.2](../E02-tests-ci/S2.2.md)) проходит на новой реализации.
