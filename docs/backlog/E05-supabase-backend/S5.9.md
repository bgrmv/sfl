# S5.9 — Бэкапы Supabase

**Эпик:** 5 — Бэкенд на Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S5.1](../E05-supabase-backend/S5.1.md)

**DESC:** Как администратор лиги, я хочу регулярные бэкапы и проверенное восстановление, чтобы не потерять историю лиги с 2011 года.

**ACs:**
- [ ] Выбран тариф с ежедневными бэкапами или настроен собственный `pg_dump` по расписанию в отдельное хранилище.
- [ ] Восстановление проверено на staging. Время записано в runbook.
- [ ] Хранится не меньше 30 дней бэкапов.
