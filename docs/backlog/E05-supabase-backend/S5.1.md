# S5.1 — Проекты Supabase и миграции схемы в репозитории

**Эпик:** 5 — Бэкенд на Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S4.1](../E04-migration-design/S4.1.md)

**DESC:** Как разработчик, я хочу staging- и prod-проекты Supabase, схему в виде миграций в git и локальную базу, чтобы изменения схемы проверялись так же, как код.

**ACs:**
- [ ] Созданы проекты `sfl-staging` и `sfl-prod` в регионе ЕС.
- [ ] В репозитории `supabase/` с конфигом и `supabase/migrations/`.
- [ ] `supabase start` поднимает локальную базу с схемой и seed.
- [ ] Миграции применяются в staging автоматически из CI, в prod — вручную подтверждённым шагом.
