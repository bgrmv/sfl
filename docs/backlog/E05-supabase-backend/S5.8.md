# S5.8 — Типы из схемы базы

**Эпик:** 5 — Бэкенд на Supabase · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S5.2](../E05-supabase-backend/S5.2.md), [S3.2](../E03-architecture/S3.2.md)

**DESC:** Как разработчик, я хочу TypeScript-типы, сгенерированные из схемы, чтобы клиент не расходился с базой.

**ACs:**
- [ ] `supabase gen types` генерирует типы в `packages/types`.
- [ ] Генерация запускается скриптом. CI проверяет, что сгенерированные типы актуальны.
- [ ] Клиентские сервисы используют эти типы.
