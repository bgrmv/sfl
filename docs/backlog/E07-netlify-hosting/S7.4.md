# S7.4 — Заголовки безопасности

**Эпик:** 7 — Хостинг клиента на Netlify · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P2 · **Размер:** S · **Зависит от:** [S7.1](../E07-netlify-hosting/S7.1.md)

**DESC:** Как пользователь, я хочу, чтобы сайт был защищён от встраивания и внедрения чужих скриптов, чтобы мою сессию нельзя было украсть.

**ACs:**
- [ ] Через `_headers` или `netlify.toml` заданы: `Content-Security-Policy` (разрешены только свой домен, Supabase и нужные CDN), `frame-ancestors 'none'`, `Strict-Transport-Security`, `Referrer-Policy`, `Permissions-Policy`, `X-Content-Type-Options`.
- [ ] Сайт проверен внешним сканером заголовков. Оценка не ниже A.
- [ ] Закрыты пункты CSP и Clickjacking из TODO в README.
