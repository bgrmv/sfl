- Работа над темой ([S10.12](../E10-product-features/S10.12.md)) тоже влияет на размер стилей: делать после неё или вместе, чтобы не мерить дважды.
- **Сделано 2026-11-17 (без браузера):**
  - Шрифты Inter и Oswald (latin, latin-ext, cyrillic) и Material Icons отдаёт само приложение (`@fontsource/*`, файлы в `media/`, подгружаются по `unicode-range`); блокирующих запросов к `fonts.googleapis.com` и `fonts.gstatic.com` больше нет (это же закрывает вопрос приватности: посетитель не ходит в Google). Класс `.material-icons` вынесен в `assets/styles/icons.scss`. Initial: 635,96 → 641,89 КБ сырых (+6 КБ CSS с `@font-face`), по сети 151,71 → 151,91 КБ.
  - Неподключённые PNG-логотипы удалены (−556 КБ из `dist`), остались WebP.
  - Бюджет `initial`: предупреждение 700 КБ, ошибка 900 КБ (было 2 МБ). Highcharts **не удалён**: его тема запланирована в [S10.72](../E10-product-features/S10.72.md), чанки ленивые и в загрузку страниц не входят; предупреждение о CommonJS снято осознанно через `allowedCommonJsDependencies: ["highcharts"]`. Предупреждение NG8113 про неиспользуемый `CaptainsToggleComponent` устранено.
