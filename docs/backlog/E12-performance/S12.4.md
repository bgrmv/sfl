## Заметки

- Создание индексов на Atlas выполняется при деплое ([S6.7](../E06-data-migration/S6.7.md)); здесь они объявляются и проверяются локально.
- Находка В1 отчёта (до 3 запросов на игрока при записи матча): сначала замерить время записи, менять, только если оно заметно.
- **Сделано 2026-11-17:** индекс `games.statistics.playerId` (explain до: `COLLSCAN`, 16 из 16 документов; после: `IXSCAN`, 14 ключей, `FETCH` 14: у игрока 14 игр), удалены одиночные `games.number` и `players.nickname`; `GET /games` отсортирован (без сезона — новые первыми, с сезоном — по номеру), без сезона ограничен 100 играми, параметры `limit` (1–500) и `offset` (это же закрывает серверную часть [S10.1](../E10-product-features/S10.1.md)); тесты `games.test.ts`, `game.schema.test.ts`; `openapi.json` обновлён. Порядок на проде и откат: [runbooks/mongo-indexes.md](../../runbooks/mongo-indexes.md).
- Сам вызов без сезона для клиента не меняется: он всегда присылает `season`. Поведение API для вызовов без `season` изменилось (порядок и лимит): допустимо, потому что публичный маршрут отдавал 43 МБ на рост лиги.
