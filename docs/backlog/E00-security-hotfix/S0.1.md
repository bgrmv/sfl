# S0.1 — Закрыть изменяющие эндпоинты авторизацией

**Эпик:** 0 — Hotfix безопасности текущего прода · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P0 · **Размер:** M · **Зависит от:** —

**DESC:** Как администратор лиги, я хочу, чтобы только авторизованные пользователи могли создавать, изменять и удалять матчи, игроков, команды и роли, чтобы посторонний не мог испортить данные лиги.

**ACs:**
- [ ] JWT-проверка выполняется глобальным `APP_GUARD`, а не через `forRoutes(...)` в `AppModule`.
- [ ] Публичные маршруты помечены декоратором `@Public()`: `POST /auth/sign-in`, `POST /auth/sign-out` и все `GET` для `games`, `players`, `teams`, `charts`.
- [ ] Все `POST`, `PUT`, `PATCH`, `DELETE` для `games`, `players`, `teams`, `roles` без токена возвращают `401`.
- [ ] `GET /users` и `GET /migrations/*` остаются закрытыми.
- [ ] Клиент работает как раньше: администратор после входа может создать и изменить матч.
- [ ] Есть автотест, который проходит по всем маршрутам и проверяет `401` без токена ([S2.4](../E02-tests-ci/S2.4.md) можно начать с этого теста).
