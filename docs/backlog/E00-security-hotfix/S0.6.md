# S0.6 — Вынести SSL-passphrase из кода

**Эпик:** 0 — Hotfix безопасности текущего прода · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P0 · **Размер:** S · **Зависит от:** —

**DESC:** Как разработчик, я хочу, чтобы passphrase и пути к сертификатам задавались через переменные окружения, чтобы секреты не хранились в коде.

**ACs:**
- [ ] В `server-nest/src/main.ts` нет строки `passphrase: 'sfl.com'`.
- [ ] Passphrase и пути к ключу и сертификату читаются из `SSL_KEY_PATH`, `SSL_CERT_PATH`, `SSL_PASSPHRASE` и валидируются в `configuration.ts`.
- [ ] Если эта passphrase используется где-то ещё, ключ перевыпущен.
- [ ] В README описано, как сгенерировать локальный сертификат.

## Заметки

⛔ Отменена 2026-10-25: passphrase защищает только локальный dev-сертификат (в проде на Azure HTTPS-ветка в `main.ts` не используется). На MVPS TLS завершает Caddy, а HTTPS-код и сертификаты удаляются из Nest целиком в [S7.2](../E07-vps-hosting/S7.2.md). Отдельно выносить passphrase в env нет смысла.
