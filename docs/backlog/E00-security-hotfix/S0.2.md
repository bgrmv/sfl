# S0.2 — Убрать пароль и учётные данные базы из логов

**Эпик:** 0 — Hotfix безопасности текущего прода · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P0 · **Размер:** S · **Зависит от:** —

**DESC:** Как пользователь, я хочу, чтобы мой пароль и учётные данные базы нигде не сохранялись в открытом виде, чтобы их нельзя было прочитать из логов сервера.

**ACs:**
- [ ] Из `auth.service.ts` удалён `console.log('signIn:auth service:', { email, password })`.
- [ ] Поиск по `server-nest/src` не находит логирования переменных `password`.
- [ ] Строка подключения к базе с логином и паролем не пишется в лог (сейчас её выводит `console.log` в `app.module.ts`). При необходимости логируется только хост.
- [ ] Логи на Azure Web App проверены. Файлы, где мог оказаться пароль, удалены.
- [ ] Если пароли попали в логи прода, затронутым пользователям предложена смена пароля.
