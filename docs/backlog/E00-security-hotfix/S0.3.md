# S0.3 — Валидация должна отклонять неверные данные

**Эпик:** 0 — Hotfix безопасности текущего прода · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P0 · **Размер:** S · **Зависит от:** —

**DESC:** Как разработчик, я хочу, чтобы неверное тело запроса возвращало `400` с описанием ошибок, чтобы в базу не попадали некорректные данные.

**ACs:**
- [ ] `ValibotValidationPipe` при ошибке выбрасывает `BadRequestException` с массивом `issues`, а не возвращает объект ошибки.
- [ ] Ответ содержит путь поля и сообщение для каждой ошибки.
- [ ] Unit-тест: валидное тело проходит, невалидное даёт `400`.
- [ ] Проверено, что существующие клиентские запросы проходят валидацию (нет регрессий в создании матча и игрока).
