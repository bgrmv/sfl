# S0.3 — Валидация должна отклонять неверные данные

**Эпик:** 0 — Hotfix безопасности текущего прода · **Статус:** в [индексе бэклога](../README.md)

**Приоритет:** P0 · **Размер:** S · **Зависит от:** —

**DESC:** Как разработчик, я хочу, чтобы неверное тело запроса возвращало `400` с описанием ошибок, чтобы в базу не попадали некорректные данные.

**ACs:**
- [x] `ValibotValidationPipe` при ошибке выбрасывает `BadRequestException` с массивом `issues`, а не возвращает объект ошибки.
- [x] Ответ содержит путь поля и сообщение для каждой ошибки.
- [x] Unit-тест: валидное тело проходит, невалидное даёт `400`.
- [x] Проверено, что существующие клиентские запросы проходят валидацию (нет регрессий в создании матча и игрока).

## Заметки

- **Сделано 2026-11-12.** Пайп бросает `BadRequestException` с `{ statusCode, message, issues: [{ path, message }] }`. Регрессии проверены тестом `game.dto.test.ts` на форме запроса, которую шлёт клиент (POST/PUT/PATCH матча). Создание игрока и команды клиентом не проходит через этот пайп в изменённом виде; схема команды не менялась.
