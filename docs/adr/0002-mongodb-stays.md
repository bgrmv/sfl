# MongoDB остаётся

Статус: принято
Дата: 2026-10-25

База остаётся MongoDB и переезжает в два шага: сначала прод на MVPS работает с текущим MongoDB Atlas (при переключении меняется только DNS, [S6.7](../backlog/E06-data-migration/S6.7.md)), после отключения Azure дамп переносится в Compose на MVPS ([S6.9](../backlog/E06-data-migration/S6.9.md)). Переход на Postgres рассматривался и отменён: выигрыш не окупает переписывание слоя данных и миграцию.

## Последствия

Транзакции MongoDB требуют replica set, а локально и в compose запускается одиночный сервер, поэтому составные операции откатываются вручную (так сделано в `PlayersService.createWithUsers`, [S3.12](../backlog/E03-architecture/S3.12.md)). Расчёт статистики защищают тесты на фиксированных данных ([S2.2](../backlog/E02-tests-ci/S2.2.md), [S2.3](../backlog/E02-tests-ci/S2.3.md)).
