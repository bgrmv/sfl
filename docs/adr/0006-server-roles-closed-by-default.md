# Права на сервере: закрыто по умолчанию

Статус: принято
Дата: 2026-11-13

Два глобальных guard'а: `AuthGuard` требует токен, `RolesGuard` требует роль `ADMIN`, если у маршрута не сказано иное. Исключения явные: `@Public()` (без токена) и `@Roles(...)` (другие роли; без аргументов — любой вошедший). Новый маршрут без декораторов доступен только администратору, поэтому забытый декоратор приводит к 403, а не к дыре ([S8.9](../backlog/E08-security-privacy/S8.9.md)).

## Рассмотрено

Список закрытых маршрутов (запрет по декоратору `@Roles(ADMIN)` на каждом): отклонён: пропущенный декоратор оставлял бы маршрут открытым, а аудит [S11.9](../audits/code-2026-11-13.md) как раз нашёл, что роли на сервере не проверялись нигде.

## Последствия

Роль `MODERATOR` пока ничего не может менять. Роли берутся из токена, смена роли действует до 15 минут; проверку по базе вводит [S8.12](../backlog/E08-security-privacy/S8.12.md). Матрица «роль × маршрут» проверяется тестом полноты в `server-nest/test/api/access.test.ts`.
