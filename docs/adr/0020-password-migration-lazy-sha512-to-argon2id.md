# Пароли переводятся на argon2id при входе, почта для сброса не нужна

Статус: принято (срок 12 месяцев подтверждён 2026-11-18, можно менять позже)
Дата: 2026-11-18

Сейчас пароли хранятся как SHA-512 без соли. Известно (ответы владельца 2026-11-18): аккаунтов 233, но реально войдут около 10 активных игроков, в день выхода — 2–3 человека, потом ожидается около 10 в день. Адреса `@sfl.lv` выдуманы, чтобы проходила валидация формы, ящиков за ними нет. Сайт остаётся летописью, большинство игроков аккаунт не подключит.

**Решение.**

1. **Ленивый перевод.** При успешном входе сервер проверяет старый SHA-512, сразу сохраняет argon2id и помечает хеш признаком алгоритма. Новые и изменённые пароли сразу в argon2id. Реализация — [S8.7](../backlog/E08-security-privacy/S8.7.md).
2. **Сброса по письму нет.** Адреса не настоящие, поэтому письмо никому не дойдёт. Для активных игроков основной путь — вход через Google по ссылке администратора, запасной — логин и пароль по той же ссылке; сброс делает администратор новой ссылкой ([S8.13](../backlog/E08-security-privacy/S8.13.md), [S10.48](../backlog/E10-product-features/S10.48.md)). Ручная выдача паролей остаётся запасным вариантом для единиц.
3. **Не вошедшие аккаунты.** Если за 12 месяцев после выхода S8.7 аккаунт не вошёл, его SHA-512 хеш удаляется. Доступ возвращается только ссылкой от администратора. Аккаунт и игрок в летописи остаются, удаляется только возможность войти по старому паролю.
4. **Почтовый сервер не поднимаем.** Свой SMTP на VPS не нужен: доставляемость хуже, чем у внешних сервисов, исходящий порт 25 у VPS-провайдеров часто закрыт, а Google OAuth снимает потребность в письмах. Если почта всё же понадобится (уведомления), берём внешний сервис отправки писем.

**Чем платим.** Пока S8.7 не выпущена, все 233 хеша остаются SHA-512; у тех, кто не войдёт, они исчезнут через 12 месяцев. Забытый пароль решает только администратор, на 10 активных игроков это приемлемо.

## Рассмотрено

- **Сброс для всех по письму.** Адреса выдуманные, письма не дойдут.
- **Ручная выдача паролей всем.** Для 233 аккаунтов, из которых активны около 10, лишняя работа; оставлена как запасной путь.
- **Свой почтовый сервер на MVPS.** Отклонено, см. пункт 4. Условия MVPS по порту 25 не проверены (вопрос поддержке, не блокирует).
- **Принудительная смена паролей.** Невозможна без почты и ломает вход активным.
