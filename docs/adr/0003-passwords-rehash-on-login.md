# Пароли переводятся на современный хеш при входе

Статус: принято (алгоритм argon2id или bcrypt выбирает [S4.3](../backlog/E04-migration-design/S4.3.md), реализация — [S8.7](../backlog/E08-security-privacy/S8.7.md))
Дата: 2026-10-25

Сейчас пароли хранятся как SHA-512 без соли, это подбирается быстро. Пользователям ничего не нужно делать: при успешном входе сервер проверяет старый хеш и сразу сохраняет новый, с признаком алгоритма в записи. Пока не все вошли, оба вида хеша поддерживаются; по истечении срока из S4.3 оставшиеся старые хеши удаляются скриптом.

## Рассмотрено

Принудительный сброс паролей по почте не годится: неизвестно, существуют ли ящики пользователей (открытый вопрос №2 в [индексе бэклога](../backlog/README.md)).

## Последствия

Аккаунты, в которые не заходят, остаются на старом хеше до срока удаления, потом им нужен сброс пароля администратором (`POST /users/:id/password`, [S8.9](../backlog/E08-security-privacy/S8.9.md)). Пока перенос не сделан, вход нужно защищать от перебора ([S8.11](../backlog/E08-security-privacy/S8.11.md)).
