# Единый ответ API: `Result<T, E>`

Статус: принято
Дата: 2026-11-15

Каждый ответ API — это `Result<T, ApiError>`, как `Result<T, E>` в Rust. По сети идёт `{ "ok": true, "data": ... }` или `{ "ok": false, "error": { status, code, message, issues? } }` (`SerializedResult` в `@sfl/schemas`). Дискриминатор `ok` позволяет TypeScript сузить тип без приведений. HTTP-статус остаётся осмысленным: 2xx для `ok: true`, 4xx и 5xx для `ok: false`, поэтому кеши, прокси и мониторинг работают как обычно.

В коде `Result` — это `Ok` и `Err` с методами `map`, `mapErr`, `andThen`, `match`, `unwrapOr`; `fromSerialized` превращает JSON обратно в контейнер, `fromPromise` — граница с кодом, который бросает исключения. Ошибка `ApiError` близка к RFC 9457: статус, стабильный машинный `code` (`NOT_FOUND`, `VALIDATION_FAILED`, ...), читаемый `message`. Клиент ветвится по `code`, а не по тексту.

**Где что.** Сервер остаётся в идиоме Nest: внутри бросает исключения (`throw new NotFoundException()`), контроллеры возвращают обычные значения. На границе `ResponseInterceptor` оборачивает значение в `ok(...)`, `AllExceptionsFilter` превращает исключение в `err(...)`. Клиент: `HttpService` достаёт `data`, а `toResult()` даёт `ApiResult<T>` там, где экран реагирует на ошибку.

**Правило данных.** Нет сущности — это ошибка (`NOT_FOUND`), нет необязательного поля внутри сущности — это успех с `null` в поле. `null` вместо ошибки не возвращаем.

## Рассмотрено

- **Сырые значения и ошибки как есть.** Дёшево, но у ответов нет общего типа, ошибки Nest приходят в трёх разных формах.
- **`{ data }` и `{ error }` без `ok`.** Различать по наличию ключа хуже, чем по явному дискриминатору.
- **Библиотека `neverthrow` или Effect.** Новая зависимость ради десятка методов. Собственный `Result` на 100 строк достаточен; если понадобится `ResultAsync` и `safeTry`, вернёмся к `neverthrow` ([AGENT.md](../../AGENT.md): зависимости только по причине).
- **Возвращать `Result` из сервисов вместо исключений.** Идёт против идиомы Nest и фильтров, переписывает весь серверный код. Откладываем, монада живёт на сетевой границе и на клиенте.

## Последствия

Ответ не совместим со старым: клиент и сервер обновляются вместе (одна ветка, `pnpm check`). `meta` для пагинации ([S10.1](../backlog/E10-product-features/S10.1.md)) добавляется в `SerializedResult` при необходимости. Форму ответа описывает OpenAPI из [S3.19](../backlog/E03-architecture/S3.19.md).
