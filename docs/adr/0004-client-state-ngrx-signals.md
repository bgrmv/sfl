# Состояние клиента на `@ngrx/signals`

Статус: принято
Дата: 2026-11-13

Клиент хранит состояние в `@ngrx/signals` (signal stores), а не в `@ngrx/store` с редьюсерами и не в RxJS-сервисах: меньше шаблонного кода, сигналы согласуются с остальным Angular 22. `provideStore()` без редьюсеров удаляется, devtools подключаются способом для signal store или убираются ([S3.7](../backlog/E03-architecture/S3.7.md)). Новый код пишется на сигналах; RxJS остаётся там, где нужны потоки (HTTP, события).

Дополнение 2026-11-13: стор должен быть один. Что происходит с остальными библиотеками NgRx и с формами — в [0007](0007-signal-forms-single-store.md).
