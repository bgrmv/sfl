# Админка — отдельный ленивый раздел клиента, фото на диске сервера

Статус: принято
Дата: 2026-11-17

История [S10.19](../backlog/E10-product-features/S10.19.md) просит вынести администрирование из публичных страниц и добавить фотографии. Здесь два решения.

## 1. Админка: ленивый раздел одного приложения

Админка — отдельный корневой маршрут `/admin` с собственной оболочкой (боковая панель), ленивой загрузкой (`loadComponent`) и охранником `authGuard` (роль `ADMIN`, [roles.md](../roles.md)). Остаётся в том же приложении Angular, слой FSD `pages/admin`.

**Почему не отдельное приложение:** один репозиторий, одна сборка, общие `shared` и `entities` (игроки, матчи), один вход и одна сессия ([ADR 0012](0012-tokens-in-memory-and-httponly-cookie.md)); публичный бандл от админки не растёт, потому что раздел ленивый (проверено сборкой: чанки страниц админки отдельные). Права всё равно проверяет сервер. Пересмотреть, если админка получит свой релизный цикл или другую команду.

## 2. Фото: файлы на диске сервера, описание в MongoDB

- **Хранилище.** Файл лежит в каталоге `MEDIA_DIR` (по умолчанию `server-nest/_media`, в `.gitignore`; на VPS это том Docker, [S7.2](../backlog/E07-vps-hosting/S7.2.md)) под случайным именем `<uuid>.<jpg|png|webp>`. Описание — коллекция `media` (`mime`, `size`, `caption`, `gameId`, `playerId`, даты). Имя файла наружу не отдаётся: адрес снимка `GET /rest/media/:id/file`.
- **Формат и размер.** JPEG, PNG, WebP до 5 МБ (`@sfl/schemas`: `MEDIA_MIME_TYPES`, `MEDIA_MAX_BYTES`). Тип определяется по первым байтам, а не по имени и заголовку браузера; SVG и GIF не принимаются (в SVG бывает скрипт).
- **Раздача.** Публичная, с `X-Content-Type-Options: nosniff` и долгим кэшем (`immutable`: файл по id не меняется). Список `GET /media?gameId=&playerId=` публичный, запись только `ADMIN`.
- **Видео и миниатюры не сделаны.** Миниатюры нужны при сотнях снимков: тогда добавляется обработка (`sharp`) и несколько размеров; видео потребует потоковой отдачи и другого лимита. Объектное хранилище (S3-совместимое) подключается за тем же сервисом, когда диска VPS станет мало.

## Персональные данные

Снимки могут показывать людей, а JPEG хранит метаданные EXIF (время, иногда координаты). Сейчас EXIF не вычищается (нет библиотеки обработки). Пока это ограничение записано в форме загрузки («публикуйте только то, с чем согласна лига») и в [S8.4](../backlog/E08-security-privacy/S8.4.md): вычищать EXIF при добавлении обработки изображений и описать удаление снимка по просьбе игрока (удаление уже работает: `DELETE /media/:id` убирает запись и файл).

## Последствия

Каталог `MEDIA_DIR` входит в бэкап наравне с базой ([mongo-backup.md](../runbooks/mongo-backup.md) описывает только базу: копию каталога добавить при выкладке). Строка в матрице `access.test.ts` и тест `media.test.ts` держат права и проверку типа.
