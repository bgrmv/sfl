# Исходники холста «Табло»

Копия досок дизайн-артефакта «SFL UI Kit» (claude.ai; раньше назывался «SFL: дизайн «Табло»»). Нужна, чтобы дизайн не зависел от внешнего сервиса: каждый файл `*.dc.html` — одна доска (компонент дизайн-холста), `canvas.json` — расположение досок и подписей секций.

- Это макеты с выдуманными данными, не код приложения. Не форматируйте их prettier: у файлов своя разметка (`<sc-for>`, `<sc-if>`, `<dc-import>`), хук pre-commit их пропускает.
- Файлы со словами `Phone` — ширина 360, `Light` — светлая тема. Обзор страниц и блоков: [feature-review.md](../feature-review.md).
- Заглушки `Scoreboard-*` и `Main` подключают компонент `Home` через `<dc-import>`.
- Устаревшие направления («Clean», «Pitch») сюда не скопированы.
- Файл `support.js` и шаблон холста поставляет сам артефакт, в копии их нет. Чтобы открыть макеты, загрузите файлы в дизайн-артефакт того же типа.

Тема: основная тёмная (решение 2026-11-15), доски со словом `Light` справочные, светлую тему делаем в самом конце ([S10.50](../../backlog/E10-product-features/S10.50.md)); новые доски рисуются только тёмными.

Доски `FlipBoard`, `FlipBoardPhone`, `SeasonRibbon`, `SeasonRibbonPhone` (секция 7 холста) добавлены в репозитории 2026-11-16 по коду клиента ([описание](../flip-board-and-ribbon.md)); в артефакт на claude.ai они загружены (проверено 2026-11-17: файлы там и в репозитории одного размера), на рендере в браузере не проверены. Телефонные доски — копии: ширину задаёт `canvas.json`.

Доски `PlayerChip`, `PlayerChipPhone` (секция 8 холста) добавлены в репозитории 2026-11-17 по коду клиента (`sfl-player-chip`, [S3.28](../../backlog/E03-architecture/S3.28.md)): строка игрока, её варианты и два блока, которые ещё предстоит вынести (шапка игрока, карточка рейтинга). Загружены в артефакт «SFL UI Kit» 2026-11-17 (версия 62), файлы там и в репозитории совпадают побайтно; на рендере в браузере не проверены.

Доски `CaptainsDuel`, `CaptainsDuelPhone` (секция 9 холста) добавлены 2026-11-17 по истории [S10.76](../../backlog/E10-product-features/S10.76.md): «битва капитанов» на главной (карточка боя, сравнение, личные встречи, состояния). Загружены в артефакт «SFL UI Kit» (версия 63), данные на досках выдуманы, на рендере в браузере не проверены.

Доски `CaptainsPoster`, `CaptainsPosterPhone` (секция 10 холста) добавлены 2026-11-17 по историям [S10.77](../../backlog/E10-product-features/S10.77.md) и [S10.78](../../backlog/E10-product-features/S10.78.md): афиша боя, полоса шансов, превью ссылок. Фигуры на афише нарисованы для примера (SVG в самой доске); доска `CaptainsDuel` теперь использует ту же афишу. Загружены в «SFL UI Kit» (версия 64), на рендере в браузере не проверены. Названия блоков каждой доски сведены в таблицы «Блоки макета» в историях S3.28, S10.76, S10.77, S10.78.
