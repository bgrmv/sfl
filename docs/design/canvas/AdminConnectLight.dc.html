How it stays safe

  • The link works once and for 24 hours, and only for the chosen player. After use or revoke it is dead.
  • The link is stored only as a hash; the admin sees it once, right after creation.
  • Admins never see the Google address of the player, only “connected via Google”. A password is stored only as a hash and nobody can read it.
  • No e-mail is used: if a password is forgotten, the admin gives a new link with “Reset access”.
  • Every create, use and revoke is written to the audit log; attempts are rate-limited.
