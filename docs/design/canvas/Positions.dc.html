Positions

Every position has an icon, a short code and a name. The icon helps to find the position at a glance in a list; it never replaces the word, so the list stays readable without colour or icon. The same icons are used in the statistics form, the draft, the squads and the line-up map.

Picker (desktop)

A native select cannot show icons inside the list, so the picker is a button with a list. It opens with Enter or arrow down, moves with arrows, picks with Enter, closes with Escape (listbox pattern).
