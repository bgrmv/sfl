Icon set

One set for the whole product: 24 × 24, line 2 px, colour from the text. The same icons appear on cards, in the game summary, in the statistics form and in the legend. They become one SVG sprite (docs/design/icons.svg, <use href="#goal">). An icon never stands alone: a word or an aria-label is next to it.
