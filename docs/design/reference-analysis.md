# Референс sport.kornatovsky.lv: страницы, функции и перенос в SFL

Анализ для [S10.11](../backlog/E10-product-features/S10.11.md), 2026-11-15. Источник: обход публичных страниц [sport.kornatovsky.lv](https://sport.kornatovsky.lv/) («Субботняя Лига», любительский пляжный футбол в Юрмале; WordPress, тема Newsphere). Цвета и шрифты референса получить нельзя (страницы читались как текст и разметка), поэтому берём **структуру и функции**, а визуальный язык — свой («Табло»: жёлто-чёрный, бежево-чёрный в светлой теме).

## 4. Принятое решение по направлению

Выбрано направление **«Табло»**: жёлто-чёрная тёмная тема и бежево-чёрная светлая. Остальные два направления («Газон», «Чистый») не развиваем. Подробности, палитра и контраст — в [brief.md](brief.md), раздел 7.
