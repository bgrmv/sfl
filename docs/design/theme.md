# Тема «Табло» и SFL UI Kit клиента

Тема заменила prebuilt-тему Angular Material (`deeppurple-amber`). Макеты: [canvas/](canvas/README.md), обзор: [feature-review.md](feature-review.md).

## Токены

Все цвета, радиусы, шрифты и отступы — CSS-переменные `--sfl-*` в `client/src/assets/styles/tokens.scss`. Новые компоненты берут значения только оттуда.

| Токен                                 | Тёмная тема           | Смысл                                   |
| ------------------------------------- | --------------------- | --------------------------------------- |
| `--sfl-bg` / `--sfl-surface`          | `#0D0C0A` / `#16140F` | фон страницы, карточка                  |
| `--sfl-text` / `--sfl-muted`          | `#F6F1E4` / `#B3AA94` | основной и вторичный текст              |
| `--sfl-accent` / `--sfl-on-accent`    | `#FFD21F` / `#0D0C0A` | один акцент; на нём только тёмный текст |
| `--sfl-neg`                           | `#FF8A7F`             | ошибка, поражение                       |
| `--sfl-font-head` / `--sfl-font-body` | Oswald / Inter        | заголовки и числа / текст               |

Светлый набор лежит в `:root[data-theme='light']` как заготовка для [S10.50](../backlog/E10-product-features/S10.50.md); не включён.

Angular Material остаётся только как слой поведения (диалоги, таблицы, автодополнение): его системные переменные `--mat-sys-*` в `theme.scss` ссылаются на токены `--sfl-*`.

## Шкала типографики и размеры

Значения сняты с досок холста и записаны токенами; страницы берут их через классы kit.

| Что                         | Значение                                 | Токен / класс                                        |
| --------------------------- | ---------------------------------------- | ---------------------------------------------------- |
| h1                          | Oswald 600, 39px                         | `--sfl-fs-h1`                                        |
| h1 компактный               | 31px: админка, список игр, вход, главная | `--sfl-fs-h1-compact`, класс `k-compact` на странице |
| h2                          | Oswald 600, 25px (22px в `k-compact`)    | `--sfl-fs-h2`, `--sfl-fs-h2-compact`                 |
| h3                          | **Inter 700, 16px, без капса**           | `--sfl-fs-h3`                                        |
| Текст, мелкий, подпись      | 16 / 14 / 13 / 12px                      | `--sfl-fs-body`, `-sm`, `-xs`, `-label`              |
| Ширина страницы             | 1080px                                   | `k-page` (`--sfl-page`)                              |
| Широкая: главная, календарь | 1180px                                   | `k-page--wide`                                       |
| Узкая: список игр           | 880px                                    | `k-page--narrow`                                     |
| Шаг между блоками           | 24px; 28px игрок и матч; 20px списки     | `k-page`, `k-page--loose`, `k-page--tight`           |
| Сетки главной               | 340px (верх), 300px, KPI 210px           | `k-grid-hero`, `k-grid`, `k-grid-kpi`                |
| Таблица                     | ячейки `10px 12px`, поверхность с рамкой | `k-table` внутри `k-scroll`                          |

**Секция или карточка.** На досках страницы игрока, матча и сезонов состоят из секций с заголовком h2, а карточки с заголовком h3 лежат внутри секции. В коде это `sfl-section` (h2, без рамки) и `sfl-card [sub]="true"` (h3). На главной блоки — самостоятельные карточки (`sfl-card` с h2 22px).

**Система счёта выбирается в шапке** (принцип P14, доска `SystemSelect`). Выбор хранит `RatingSystemStore` (`shared/store/rating-system.store.ts`, запоминается в браузере); страницы с рейтингом читают его и своих переключателей не имеют.

## SFL UI Kit (`client/src/shared/ui/kit`)

Подключение: `imports: [...KIT]`. Состав: `sflBtn`, `sfl-card`, `sfl-badge`, `sfl-avatar`, `sfl-form-dots`, `sfl-stat`, `sfl-segmented`, `sfl-page-head`, `sfl-state`, `sfl-split-bar`, `sfl-section`, таблицы (`th[sflSortKey]`, `sfl-filter-bar`, `sfl-sort-select`), `sfl-flip-digits` и `sfl-season-ribbon` ([описание](flip-board-and-ribbon.md)), графики `sfl-sparkline`, `sfl-bars`, `sfl-radar`, `sfl-pitch`, `sfl-scoreboard`, `sfl-month`, значки `sfl-icon`. Блок с данными игрока `sfl-player-chip` живёт не в kit, а в `entities/player/ui` ([ADR 0016](../adr/0016-client-fsd-layers-and-cross-imports.md), п. 7). Каждому графику заданы `role="img"` и текстовая альтернатива; цвет не единственный носитель смысла (W/D/L буквами). Глобальные утилиты (`k-page`, `k-grid`, `k-table`, `k-input`…) — `assets/styles/kit.scss`.

## Feature flags блоков

Реестр — `client/src/shared/config/feature-flags.ts`, один ключ на блок или страницу дизайна.

- `enabled: true` — блок показывается (`*sflFeature="'home.vote'"`).
- `dummy: true` — блок показывает **выдуманные** данные из `@shared/dummy`: вид готов, настоящих данных нет. Поле `needs` говорит, что подключить (стор, сервис, история).
- В dev-режиме на таком блоке виден значок «dummy» (`SHOW_DUMMY_MARKERS`), в разметке стоит `data-dummy`, рядом комментарий `DUMMY (<ключ>): …`.
- Подключили данные — ставьте `dummy: false` (функция `live(...)`) и уберите импорт из `@shared/dummy`.

Список блоков с `dummy: true` — это очередь работ по «функциональной части».

## Страницы и маршруты

Рабочие страницы старого вида остались под `/legacy/*` (Material) до переноса форм ([S10.72](../backlog/E10-product-features/S10.72.md)).

Что уже читает настоящие данные (флаг `dummy: false`): список игр, страница матча (счёт, капитаны, MVP, бомбардиры, составы, история), рейтинг игроков, страница игрока (числа, очки по играм, форма, источники очков, сезоны, результаты капитана), капитаны, сезоны, сравнение двух игроков, календарь суббот, главная (следующая суббота, последняя игра, цифры сезона, топ, форма, мини-календарь, капитаны, последние игры), админка игроков и дашборд черновиков, профиль (аккаунт).

Остальное — dummy: очередь работ описана историями [S10.56–S10.72](../backlog/README.md). Расчёты рейтинга на клиенте не дублируют правила: сервер считает метаданные игроков (`@sfl/domain`), `entities/player/lib/player-stats.ts` только выбирает, сортирует и форматирует.
