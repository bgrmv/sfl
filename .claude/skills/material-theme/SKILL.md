# Тема Angular Material

Работай вместе с frontend-design: он помогает выбрать направление, этот skill задаёт, как оформить выбор в проекте.

## Правила

1. **Один источник токенов.** Цвета, типографика и плотность задаются темой Material (`client/src/assets/styles/theme.scss`) и токенами. В компонентах нет «магических» hex-значений и размеров шрифта.
2. **Тема целиком, не заплатками.** Сначала направление (S10.11): 4–6 именованных цветов, роли шрифтов, плотность. Затем тема Material (S10.12), затем страницы (S10.13).
3. **Светлая и тёмная** строятся из одних токенов; переключение по `prefers-color-scheme` и ручной выбор сохраняется.
4. **Контраст.** Текст ≥ 4.5:1, крупный текст и границы ≥ 3:1. Цвет не единственный носитель смысла (победа/поражение).
5. **Типографика.** Не больше двух гарнитур, шкала размеров токенами, строка < 80 символов, шрифты локально или из проверенного источника.
6. **Компоненты.** Сначала штатные компоненты Material и их токены; свои стили поверх только если токена нет. API темизации зависит от версии — сверяйся с документацией Angular Material 22.
7. **Проверка.** После изменений: `pnpm check`, затем визуальная проверка главной, входа, матчей и игроков в обеих темах.
